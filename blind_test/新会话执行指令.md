## 跳读的做法

路由表里的目标写成 `R84 L4629` 这样的形式，意思是：**引擎 `hxs_engine_v79_full.md` 第 4629 行起**。

```bash
sed -n '4629,4700p' hxs_engine_v79_full.md
```

**只读你被指向的那一段，不要通读引擎。**（引擎 16,000+ 行，通读既不可行，也会污染你对其他例的判断。）

若路由目标指向 `term_layer/` 下的文件（属禁读区）——**不要打开，在记录里写「目标在禁读区，未读」。** 这本身是有效数据。
