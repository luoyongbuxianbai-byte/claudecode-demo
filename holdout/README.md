# 留出保留区（协议11）

**本目录内的一切内容，引擎侧零消费。**

## 状态

**空。** 第二期矿脉尚未开工，故尚无任何语料入区。

## 制度（协议11 全文见 `../回归测试协议.md`）

- 每个新语料源的验案，按七族分层随机抽 **≥30%（且不少于30则）** 入区；
- 入区案例：**不誊⑤呈现校准、不立验案锚、不作守卫、不入引擎正文任何位置**；
- **只用于泛化准确率测量**；每次动用后标"已曝光"，**不复用**；
- 映射表加密留档，与引擎仓库分离（本目录只存去标识后的测试件与清单）。

## 为什么要有这个目录

C卷 111 则验案已被 X-0 工序全数消化进引擎（107 个带验案之方中，92 个的 ⑤呈现校准
明标"由该案提炼"）。**留出集当场烧光——这是引擎至今拿不出任何泛化证据的直接原因。**

这个目录的存在，是为了让第二期矿脉不重演同一件事。
