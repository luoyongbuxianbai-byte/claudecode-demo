# ⛔⛔ 失效声明（98批）

**本目录之全部盲测判分结果自 98批 起作废，不得再作为「盲测」证据引用。**

**理由**：引擎内有 **222 处「呈现校准」**，系 **C卷验案之改写摘要**；而 `holdout/cases` 之案出自**同一批验案**。
二字串重合实测：41 例中 **≥12 者 5 例（确证同源）｜8–11 者 16 例（可疑）｜合计 21／41 ＝ 51%**。

**最刺眼一例**：`H032` 与引擎 L9211 重合 **19 个二字串**——引擎原文「**桂枝汤加荆芥防风为合法化裁**」，而该案答案即「与桂枝汤加荆防」。**答案连同化裁逐字在引擎内，且以本案原症状为键。**

**⛔ 关键**：改写不是复制，故历批所用之「逐字指纹核」结构上查不到它。
**发现者是 98批 盲测之判题者（新会话）**——它不知道答案，只能靠「怎么这么像」起疑；**知道答案的人会把重合当作判对了。**

**后续盲测源只能是**：①真实新病人（答案在未来）②引擎语料之外的医案集（须先做二字串重合核）。
