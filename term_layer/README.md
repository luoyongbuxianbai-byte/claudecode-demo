# term_layer — 胡希恕原词—方证结构库（L0→L1→L2）

**冻结边界（上级指令 1-9）**：本目录只做取证，**不建轴、不判类别、不合并同义词、
不据统计造禁止关系、不据形式组合补格**。未经 L3 验证者**不得进入引擎规则**。

| 文件 | 层 | 内容 |
|---|---|---|
| `L1_原词定义库.md` | L1 | 胡老显式定义句全量（"X，指/即/谓/就是…"），一词多义不合并 |
| `L2_关系库_证到方.md` | L2 | **同句内**明确表达的「条件 → 方」，跨句因果不收 |
| `L2_关系库_禁忌.md` | L2 | 原文显式「不可X」句 |
| `一词多义实测表.md` | L1 | 同词不等义实测（含 001/002/003 硬性回归案例） |
| `_term_raw.json` | — | 结构化原始数据 |

**复跑**：`python3 tools/term_db.py`（幂等）。文件头带【已知失效模式】【弃件条件】【口径】。

## 本层记录的三次工具自查（视角㉑：工具的错要和结论一起报）
1. 讲座类书是口语转录，「这个…就是…」是话语填充非定义 → 立弃件闸门，弃 782 条。
2. **「者，」被误当定义引导词**，把条文条件句（"小便不利者，五苓散主之"）全部收成假定义
   （小便不利×26 全假）→ 已移除该分支，定义句从 5012 降到 **2586**，降幅 48%。
   **降下来的才是真数。**
3. 证据等级只能机械分 A/B；C（序言/他人转述）须人工标，工具不产。
