# 三条脉象裸映射 · 逐条审计（123批·上级令三）

> ⛔ 上级令三：**不准成组处理。** 三格各自独立做 source／object／scope／counterexample 四审。
> ⛔ 上级令一：**肠痈反例只挂到它实际证伪的传播链上**，不得越权用它否定所有「数—热」关系。
> 机器件：`rules/pulse_cells_v0.json`（schema `schema/pulse_cell_v0.json`）。

## 〇、先订正我 122批 第八节的论证

我 122批 写：

> 「`数=热｜洪大=阳明气分` 与『脉洪数者，脓已成，不可下』**直接冲突**。」

**该句过当，已撤。** 肠痈条直接证伪的是这条**跨层直通**：

```
脉数/洪  →  热实  →  可攻下
```

它**不**证明：数脉从不主热｜洪脉与阳明气分毫无关系｜洪数与热无关。

⇒ **同一观察项可以同时支持多个状态变量；最终 Decision 还须受 Stage、病理产物、禁忌共同约束。**
⇒ 故三格**皆未改写为「数≠热」之类**。所改者是【效力等级】与【scope】，不是【方向】。

## 一、`数=热` → `PULSE-SHU-HEAT`

| 审 | 结果 |
|---|---|
| **source** | ✅ **有源**。「数主热」检得：C卷 3｜讲伤寒 3｜解读 3｜传真系 3｜病位类方解 3。〔A·讲伤寒·146485〕「这个脉数，**数主热**，一般这个脉的证侯是如此的」 |
| **object** | ✅ 对象＝【热】，逐字 |
| **scope** | ⛔ **原格无 scope**。本批只查得【例外域】，**未能给出正作用域** ⇒ 不晋升 |
| **counterexample** | ⭐ **胡老自陈**〔A·讲伤寒·146752〕「**这个数脉，也不光主热，也主虚**……数呢是客热……**所以它不是胃里真有热**，并不是胃气强」<br>⭐〔A·C卷·5156 §122〕「**数为热者，不能消谷，以胃中虚冷，故吐也**」——脉数而胃中虚冷<br>⚠ 异文：讲伤寒同条作「**数为客热**」，C卷作「数为热者」⇒ `text_status=disputed` |

**裁**：`validation_status=counterexample_audited`｜`compile_status=support_only`

**本格不能判**：
- ⛔ 不能定【可攻下】——热与可攻是两件事
- ⛔ 不能排除【虚】——胡老明说数亦主虚
- ⛔ 不能定【热之部位】
- ⛔ 单见脉数不得 `confirm` 热

> **本格之病不在「数不主热」，在【无 scope，且被当作可直通治疗决策之硬映射】。**

## 二、`洪大=阳明气分` → `PULSE-HONGDA-YANGMING`

| 审 | 结果 |
|---|---|
| **source** | ⛔⛔ **无源**。「**阳明气分**」**全库零命中**：C卷 0｜讲伤寒 0｜讲金匮 0｜解读 0｜传真系 0。（「气分」二字单独有 6/4/19/8/7 处，**连用作「阳明气分」者 0 处**） |
| **object** | ⛔ 对象术语不在语料。胡老实际用语为【**里热盛／热盛于里**】：〔A·C卷·14884〕「**脉洪大为热盛于里**，如何可与桂枝汤？」；〔A·C卷·54218〕「若脉洪大**为里热盛**」 |
| **scope** | ⛔ 无 |
| **counterexample** | ⚠ **本批未查得可用反例。**<br>⛔ 唯一候选 §25「服桂枝汤，大汗出，**脉洪大者，与桂枝汤，如前法**」**不可用**——胡老判其为传抄之误并径改字：「**脉洪大，当是脉浮**……必是传抄有误，宜改之」〔C卷·14884〕；另本更疑「**可能是白虎加人参汤的脉洪大错乱在此**」〔C卷·54218〕。<br>⇒ **引之为反例，即是拿胡老已否定之文本当证据。** |

**裁**：`validation_status=unsourced_rejected`｜`compile_status=fail_closed`

⛔ **须分清两种否决**：
- **以反例否决** ＝ 这句话被原文推翻
- **以无源否决** ＝ **这句话本工程根本没有权利说**

本格属后者。⇒ 这不是「规则过宽」，是**术语走私**：温病学语混入胡老体系而无人察。

⚠ **「未查得反例」不等于「不存在反例」**——检索只覆盖已拟之式〔闸门9⑦〕。

## 三、`结代=心血虚炙甘草` → `PULSE-JIEDAI-ZHIGANCAO`

| 审 | 结果 |
|---|---|
| **source** | ⚠ **半有源**：状态侧有源但**用词不同**——胡老作【**津血枯燥**】〔A·C卷·145454〕「此治**津血枯燥而脉结代**」；「**血不足以荣脉，则脉结代**」〔145461〕。⛔ 而原格所用「**心血虚**」**全库零命中**（九书逐本皆 0） |
| **object** | ⛔⛔ **一格跨三级**：脉象 → 病机 → 方剂 |
| **scope** | ⚠ 有条件但原格未写：须与【**心动悸**】并见。〔A·C卷·145968〕辨证要点「**心动悸，脉结代**气阴两虚者」 |
| **counterexample** | ⭐⭐ **直接证伪**〔A·C卷·145807〕「**平人脉结并不足虑，即不服药亦可自愈**」——**无病之人见结脉，不须治，更不须本方**<br>⭐ 同域禁忌〔A·C卷·145507〕「若虚服的阴虚寒重证，**脉微欲绝，或无脉者，本方不中与之**」 |

**裁**：`validation_status=falsified_overbroad`｜`compile_status=inactive`

⛔ **撤销 `结代→炙甘草汤` 直映**，二因**各自独立成立**：
1. 对象术语无源（「心血虚」0 命中）
2. 直映被原文证伪（平人脉结不须服药）

**本格不能判**：不能由脉直达方｜不能定「心血虚」｜无【心动悸】时不得支持本方证。
