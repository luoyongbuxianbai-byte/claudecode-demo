# 显隐映射表 · 人读判定册（104批立）

> **⭐⭐⭐ 立表之由（用户 104批 命题）**：
> 「**我反复强调的隐性必须又建立在显性的前提下**……仲景跟胡老也是没有完整的表达出来，
> 就像我此刻心中有全套想法跟思路但是我就是没有办法完整的系统的毫无保留的说明白。」
>
> **本表之发现**：语料里有 **148 处**，是**作者自己标出的隐性，且锚在同句**——
> 语式恒定为 `X者，暗示Y` ／ `…，言外Y` ／ `…自在言外`。
> **X ＝ 原文写出者（显性）｜Y ＝ 原文未写而作者补出者（隐性）。**
> ⇒ **这就是「有显性前提的隐性」，是语料自带的，不必我方推测。我们 103 批一次没抽过。**

**口径**：机械命中 **148 条**（暗示 59｜言外 64｜自在言外 21｜传其神 4）。
**本批人读 64 条**（言外 40 ＋ 暗示 24）＝ **43.2%**。⛔ 余 84 条未读。

## ⭐⭐⭐ 第〇节 · 胡老明标的「省文补读法」——本表之合法性根据

〔A·C卷·**66415**｜讲伤寒·**250638**（二处互证）〕
> 「条文中虽未说四五日未大便，然据『六七日不大便』一语，则四五日至六七日未大便**自在言外**。
> **古文简练，读者应细体会**（／应仔细玩味）。」

⭐ **胡老明说：仲景省文，未写 ≠ 不存在，须由文内他句补读。**

### ⛔ 与 (51)「缺省不得推定」之关系——不是冲突，是分工

| 规则 | 管辖域 | 内容 |
|---|---|---|
| **(51) 缺省不得推定** | **临床采集** | 医者未问 ⇒ 不知道，**不得推定为阴性** |
| **本表·省文补读** | **文本解读** | 仲景未写 ⇒ 古文简练，**可由文内他句推出** |

⭐⭐ **二者之界即用户所立之则**：
**「隐性必须建立在显性的前提下」＝ 补读必须指出其文内显性锚。**

⛔ **本表之硬闸门**：
**凡补出一条隐性判据，须同时写出其显性锚在何句何字。写不出锚者，即为推测，不得入库。**
（上例之锚为同句「六七日不大便」五字。）

## 一 · 显隐映射之五型（人读 64 条所得）

### 型一 ⭐⭐⭐【言外补方】——原文未出方，作者补出（量最大）

| 显性（原文写出） | 隐性（补出之方） | 锚 |
|---|---|---|
| 「心下痞，由医者误下所致」 | **言外宜先以桂枝汤解外，外解已再与泻心汤攻痞** | C卷·42104｜解读·112656（二书） |
| 「绕脐痛而烦躁，发作有时，此亦有燥屎的确候」 | **言外宜大承气汤攻之** | C卷·65360 |
| 「但阳脉微者，为卫不和于外，应责在表」 | **言外宜桂枝以发汗** | C卷·71940｜讲伤寒·112672 |
| 「脓已成，则不可以本方（大黄牡丹汤）下之」 | **言外当适证选用排脓的方药** | C卷·79288 |
| 「只是微满，出头硬后必溏，万不可攻之」 | **言外呢这就是栀子豉汤** | 讲伤寒·239935 |
| 「不可除热……热除必哕」 | **言外可以用像茵陈五苓散这类的** | 讲金匮·225845 |
| 「凡津液有所损伤之后的表证」 | 「**他这个书上没说，但是言外之意告诉你用桂枝汤**」 | 讲伤寒·66916 |
| 「服四逆汤，下利清谷已，而身疼痛不解者」 | **当然亦宜桂枝汤，自在言外** | C卷·16214｜解读·82911 |
| 「表虚里实……病尽入于里」 | **言外表不解呢，先解表，还是先吃桂枝汤** | 讲伤寒·224684 |

⭐ **本型即「条文缺方」之作者自补**——与 R44「条文挂载缺口 161 条」直接相关：
**其中一部分的方，作者已在言外补出，只是我们从没抽过这个面。**

### 型二 ⭐⭐【言外补禁忌】——原文只出证，禁忌在言外

| 显性 | 隐性（禁忌） | 锚 |
|---|---|---|
| 「**虽**汗出不恶寒，而其身必重、短气、腹满而喘」 | **「这言外就是不能吃泻药，不能够下」** | 讲伤寒·227848 |
| 「津液内竭，虽硬不可攻之」 | **言外就是不要吃承气汤类，大承气汤更不能用** | 讲伤寒·235625 |
| 「虽十日不大便，不为所苦」 | **这个言外呢，不可攻** | 讲伤寒·246495 |

⭐⭐ **注意型二全部由「虽」字引出**——**「虽」是禁忌之言外标记字**〔讲伤寒·227803〕
「**所以他搁个虽字呀**……这言外就是不能吃泻药」。**此为 CH1 自标记通道所产之第二个确证字。**

### 型三 ⭐⭐【暗示补病位／补前情】——由现有字推出未写之阶段

| 显性 | 隐性 | 锚 |
|---|---|---|
| 「脏无他病者，谓无其他内脏病」 | **「言外病在外也」** | C卷·15490｜解读·81862 |
| 「外证未解」 | **暗示服过麻黄汤而外证还未解**，当以桂枝汤类解之 | C卷·35656｜解读·105213 |
| 「太阳病不解」 | **暗示经过汗吐下等治疗而病还不解** | C卷·71998 |
| 「太阳病已经十余日」 | **暗示已传入少阳而为柴胡证** | 讲伤寒·125268 |
| 「少阴病二三日不已」 | **暗示已服麻黄附子甘草汤而病还不已** | C卷·102950 |
| 「伤寒八九日……」 | **言外的意思就是传入到半表半里，而为柴胡证** | 讲伤寒·132519 |
| 「胸满而烦」 | **言外的意思是这是柴胡证** | 讲伤寒·263834 |
| 「太阴中风」 | **暗示由太阳转属为太阴病** | 讲伤寒·274862 |

⭐⭐⭐ **「脏无他病 ⇒ 言外病在外」正是必要条件之逆用**（无里证 ⇒ 在表），
**与 103批 R96、与解读·133409「无里证则更证实邪在表」同源。**
**⇒ 显隐映射与必要条件不是两件事，隐性之推出机制主要就是必要条件之逆用。**
