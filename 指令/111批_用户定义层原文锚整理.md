## 一、八纲——资料库中的完整定义骨架  
资料库《胡希恕经方理论与实践》在“辨证施治的一般规律”中明确说：  
**“何谓八纲？八纲即指表、里、阴、阳、寒、热、虚、实而言。”**  
同时特别指出：  
**“其实，在表里中间，还有一个半表半里，按数而论，应该是九纲。由于言表里，而半表半里即寓其中，所以习惯上仍简称为八纲。”**   
胡希恕经方理论与实践.txt  
所以进入引擎后，不能把“八纲”机械理解成只有八个互斥标签。  
资料库定义实际上是：  
**病位轴：表／里／半表半里**  
**病性轴：阴／阳／寒／热／虚／实**  
其中半表半里虽不计入“八纲”名目，但属于实际病位。  
   
⸻  
   
## 1. 表、里、半表半里  
**表**  
资料库原文：  
**“表指体表，即由皮肤、肌肉、筋骨所组成的外在躯壳。若病邪集中地反应于此体部时，便称为表证。”**   
胡希恕经方理论与实践.txt  
**里**  
**“里是指人体的里面，即由：食道、胃、小肠、大肠等所组成的消化道。若病邪集中地反应于此体部时，便称为里证。”**   
胡希恕经方理论与实践.txt  
**半表半里**  
**“半表半里，是指表之内，里之外，即胸腹两大腔间，为诸脏器所在之地。若病邪集中地反应于此体部时，便称为半表半里证。”**   
胡希恕经方理论与实践.txt  
并且这是一个非常重要的硬约束：  
**“以上表、里、半表半里三者，是固定病位的反应。”**  
**“不论什么病，而其病位的反应或为表，或为里，或为半表半里。虽然，有时二者或三者同时出现，但绝对不会超越此三者的范围。”**   
胡希恕经方理论与实践.txt  
因此：  
**病位不是六经六个独立空间。**  
六经是在这三个病位之上，再叠加阴阳病性的六种基本组合。  
   
⸻  
   
## 二、阴阳——这正是我指出的核心总则  
资料库原文非常明确：  
**“阴即阴性，阳即阳性。”**  
然后给出了真正的判定基础：  
**“人体得了病，必定影响人体机能的改变。首先是代谢机能的改变。这种改变不是较正常太过，就是较正常不及。”**  
**“如其太过，则病体也必相应要有亢进的、发扬的、兴奋的……太过的病征反映出来，这类太过的病征，即称为阳证。”**  
**“如其不及，则病体也必相应要有衰退的、消沉的、抑制的……不及的病征反映出来，这类不及的病征，便称为阴证。”**   
胡希恕经方理论与实践.txt  
因此这里可以确立一个**A级定义锚**：  
**阳**  
**机能较正常太过 → 亢进／发扬／兴奋 → 阳证**  
**阴**  
**机能较正常不及 → 衰退／消沉／抑制 → 阴证**  
而不是：  
“病人说热 → 阳”  
更不是：  
“摸起来热 → 热证”  
这是指出的广州案错误的真正上位修正。  
   
⸻  
   
## 三、寒热——不是阴阳的同义词  
资料库继续明确：  
**“寒即寒性，热即热性。如果病体反映为寒象者，即称为寒证。反之，反映为热象者，便称为热证。”**   
胡希恕经方理论与实践.txt  
最关键的是：  
**“寒为不及，当系阴之属，故寒者也必阴；而热为太过，当系阳之属，故热者也必阳。”**  
但是紧接着：  
**“请注意：寒与热是具有一定特性的阴阳。所以，泛言阴不一定必寒；泛言阳，更不一定必热。”**  
最终结论：  
**“病有不寒不热者，但绝无不阴不阳者。”**   
胡希恕经方理论与实践.txt  
这给引擎一个非常重要的逻辑结构：  

| 概念  | 资料库定义         |
| --- | ------------- |
| 阴   | 机能不及          |
| 阳   | 机能太过          |
| 寒   | 阴的一种具有特定性质的表现 |
| 热   | 阳的一种具有特定性质的表现 |
| 阴→寒 | 必然            |
| 阳→热 | 必然            |
| 阴→热 | 不排除           |
| 阳→寒 | 不排除           |
| 阴→寒 | 不能反推“所有阴都是寒”  |
| 阳→热 | 不能反推“所有阳都是热”  |
  
也就是说：  
**阴阳是上位轴；寒热是具有特定性质的阴阳。**  
   
⸻  
   
## 四、虚实——资料库明确拆成两个不同对象  
这是另一个不能混淆的核心定义。  
资料库原文：  
**“虚指人虚，实指病实。”**   
胡希恕经方理论与实践.txt  
具体：  
**“如病体未愈，而人的精力已有所不支，病体反映出一派虚衰之象者，即称为虚证。”**  
**“若病势在发展，而人的精力未衰，病体反映出一派充实的征象者，便称为实证。”**   
胡希恕经方理论与实践.txt  
因此：  
**虚的对象 = 人／正气**  
**实的对象 = 病／邪气**  
这意味着：  
**“人虚而病实”在逻辑上完全可以同时成立。**  
资料库还明确指出：  
**“寒热有常，而虚实无常。”**  
并举出：  
虚而寒 → 阴 虚而热 → 阳 实而热 → 阳 实而寒 → 阴   
胡希恕经方理论与实践.txt  
所以不能建立：  
**虚 = 阴**  
**实 = 阳**  
这样的硬等式。  
   
⸻  
   
## 五、八纲最终组合关系  
资料库把这一层进一步说透：  
阳证可以是： **或热、或实、或亦热亦实、或不热不实、或热而虚。**  
阴证可以是： **或寒、或虚、或亦寒亦虚、或不寒不虚、或寒而实。**  
**“以上为八纲之梗概，必须辨认清楚。”**   
胡希恕经方理论与实践.txt  
这对你的引擎非常关键。  
因此不能采用：  
```
阳 = 热 + 实
阴 = 寒 + 虚

```
这种简化模型。  
正确结构应该是：  
```
阴/阳
  ├─ 寒/热：具有特定性质的阴阳
  └─ 虚/实：另一个维度，但其阴阳归属受寒热组合影响

```
   
⸻  
   
## 六、六经——资料库的定义  
资料库直接定义：  
**“何谓六经？六经是指太阳、阳明、少阳之三阳，太阴、少阴、厥阴之三阴而言。”**   
胡希恕经方理论与实践.txt  
随后给出六经与八纲的核心映射：  

| 六经 | 病位   | 病性组合  |
| -- | ---- | ----- |
| 太阳 | 表    | 阳、热、实 |
| 少阴 | 表    | 阴、寒、虚 |
| 阳明 | 里    | 阳、热、实 |
| 太阴 | 里    | 阴、寒、虚 |
| 少阳 | 半表半里 | 阳、热、实 |
| 厥阴 | 半表半里 | 阴、寒、虚 |
  
资料库原文明确：  
**“表阳热实即是太阳，表阴寒虚则为少阴；里阳热实即是阳明，里阴寒虚则为太阴；半表半里之阳热实即是少阳，半表半里之阴寒虚则为厥阴。”**   
胡希恕经方理论与实践.txt  
所以六经的数学结构实际上非常清楚：  
**3个病位 × 2个阴阳类别 = 6种基本证候类型。**  
资料库进一步解释：  
**“表、里、半表半里二者，都是病位的反应，而阴、阳、寒、热、虚、实六者，都是病情的反应。”**  
**“三而二之为六，即病之见于证者的六种基本类型。这即《伤寒论》所谓的‘六经病’。”**   
胡希恕经方理论与实践.txt

## 七、六经不是《内经》的经络六经  
这一点资料库反复强调，必须进入定义层，防止语义污染。  
《伤寒论》的六经：  
**“实质是证，而且是来自八纲。”**   
胡希恕经方理论与实践.txt  
另一资料库文本进一步明确：  
**“《伤寒》的六经是六个证候提纲。”**  
从病位讲，是三个病位：**表、里、半表半里**；  
从病情讲，分为**阴、阳两类**。   
解读张仲景医学_伤寒六经方证直解.txt

**不是足太阳膀胱经、足少阳胆经等经络定位。**  
资料库甚至明确指出，《内经》六经和《伤寒》六经：  
**“概念、实质则完全不同。”**   
解读张仲景医学_伤寒六经方证直解.txt

## 九、三毒——目前资料库已经确认的定义  
这里要特别谨慎。  
资料库《胡希恕病位类方解》“食、水、瘀血的毒害”一节明确提出：  
**“食、水、瘀血三者，均属人体的自身中毒，为发病的根本原因。”**   
胡希恕病位类方解.txt  
因此目前能够确认的三毒框架是：  
**① 食毒**  
资料库原文：  
**“大都不善摄生、伏食无节，因致肠胃功能障碍、或宿食不消、或大便秘结而使废物不得及时排出而便存毒物的蓄积……”**  
并明确：  
**“仲景书中谓为宿食者；即食毒的为病。”**   
胡希恕病位类方解.txt  
也就是说：  
**食毒 → 饮食失节等 → 胃肠功能障碍／宿食不消／大便秘结 → 废物不能及时排出 → 毒物蓄积。**  
资料库同时给出宿食的相关证据：  
* 脉紧如转索，无定常 → 宿食；  
* 脉涩、大，按之反涩等；  
* 脉数而滑 → 实，有宿食；  
* 下利而不欲食 → 有宿食；  
* 宿食在上脘 → 相关证治。   
胡希恕病位类方解.txt  
   
⸻  
   
**② 水毒**  
资料库明确：  
**“水毒大多由于肾脏能障碍而使液体废物蓄积的结果。”**  
同时指出：  
汗出当风、受伤取冷等，也可能使本欲由皮肤排出的废物滞留体内，形成自身中毒证。  
并明确把仲景书中的：  
**湿、饮、水气**  
归入水毒之属。   
胡希恕病位类方解.txt  
资料库还给出具体证象，例如：  
湿痹候可见**小便不利、大便反快**；  
并引用《金匮要略》湿病、痰饮相关条文继续展开。   
胡希恕病位类方解.txt  
因此当前可以建立：  
**水毒 ≠ 单纯“水多”。**  
资料库中的定义机制是：  
**液体废物蓄积／排泄障碍 → 自身中毒；**  
而“湿、饮、水气”是仲景文本中的相应表现类别。  
   
⸻  
   
**③ 瘀血毒**  
这里目前我**不能给你完整定义**。  
原因不是资料库没有，而是当前检索得到的可引用连续原文只确认了：  
**食、水、瘀血三者属于人体自身中毒，是发病根本原因。**   
胡希恕病位类方解.txt  
但我目前没有取得该章节关于“瘀血毒”连续完整定义的原文锚。  
所以按照你已经确立的规则：  
**未取得 ≠ 不存在。**  
因此此处只能暂记：

不能用我已有的中医知识替它补成“血液循环障碍”“瘀血阻滞”等未经当前资料库原文确认的句子。

这轮最重要的成果不是“多找到了几个症状”，而是**定义层终于开始闭合**：

**六经：三病位 × 阴阳的六种基本证候。**

## 一、八纲真正的结构不是“8个并列标签”  
《胡希恕经方理论与实践》把八纲明确拆成了两个不同维度：  
**① 病位维度**  
* 表  
* 里  
* 半表半里  
**② 病情维度**  
* 阴  
* 阳  
* 寒  
* 热  
* 虚  
* 实  
原文明确说：  
“表、里、半表半里”是**病位的反应**；  
而：  
“阴、阳、寒、热、虚、实”是**病情的反应**。  
 胡希恕经方理论与实践.txt  
这不是文字上的分类，而是整个体系的**类型系统**。  
因此不能把：  
表、里、寒、热、虚、实  
当成8个同性质的指标。  
更准确的抽象是：  
**病位轴 × 病情轴**  
   
⸻  
   
## 二、而“阴阳”又不是与寒热虚实平行的第五、第六个独立变量  
这一点尤其重要。  
胡希恕在另一处讲得更加直接：  
阴阳是“性”，核心是“太过/不及”。  
太过 → 兴奋、亢进 → 阳性。  
不及 → 沉衰、抑制 → 阴性。  
而寒、热、虚、实又是在阴阳这个总框架之下继续分析。  
 (最完整版)胡希恕讲伤寒论.txt  
所以更准确的结构应该是：  
```
                 病
                 │
        ┌────────┴────────┐
        │                 │
      病位              病情
        │                 │
  表/里/半表半里        阴/阳
                          │
                    ┌─────┴─────┐
                    │           │
                   寒热        虚实

```
但这里还不能把它机械地理解成“阴阳是寒热虚实的上级计算公式”。  
因为资料库自己又明确指出：  
**虚实无常，而寒热有常。**  
也就是说二者在逻辑地位上并不完全相同。  
 胡希恕经方理论与实践.txt

## 三、这直接解释了一个此前没有充分说清楚的问题：  
## “虚”不能直接等于“阴”  
资料库明确给出四种组合：  
* 虚寒 → 阴  
* 虚热 → 阳  
* 实热 → 阳  
* 实寒 → 阴  
甚至进一步说：  
阳证可以有热、实，也可以不热不实，也可以热而虚；  
阴证可以有寒、虚，也可以不寒不虚，也可以寒而实。  
 胡希恕经方理论与实践.txt  
因此：  
**虚 ≠ 阴**  
**实 ≠ 阳**  
这是必须写进引擎定义层的硬约束。  
否则一看到“虚”就往阴证走，一看到“实”就往阳证走，会直接产生系统性误判。

## 四、“热”也绝不能简化为“有热感”  
现在读到更多上下文后，这一点比我之前判断的更严重。  
资料库同时存在至少三种完全不同的东西：  
**A. 原文中的“热”**  
例如：  
发热恶寒 身热 不恶寒反恶热  
这些是条文证候。  
**B. 医者根据整个证候结构判断“热”**  
例如阳明：  
“身热，汗自出，不恶寒反恶热”  
胡希恕进一步解释为：  
热结于里以后，热势外达，所以出现身热。  
 胡希恕经方理论与实践.txt  
这里已经是**证候 → 病性解释**。  
**C. 患者的主观热感**  
例如：  
“自感口如含火炭”  
这个属于患者的感觉。  
资料库中确实有医案把它与发热、口渴、脉滑数等共同放在阳明热盛津伤的完整证候中判断。  
 经方传真_胡希恕经方理论与实践.txt  
但是：  
**这不能反推“任何主观热感本身就是热证充分条件”。**  
尤其资料库还明确给出反例：  
外面看起来热，实际上里头大寒；  
手足厥冷，里面却是真热；  
甚至直接警告：  
**“不能够只就表面上看我们就来确定寒热了。”**   
(最完整版)胡希恕讲伤寒论.txt  
所以之前指出的广州案问题，现在从资料库内部证据来看，已经不是一个孤立的经验问题。  
它是一个**判据层级错误**：  
```
主观感觉
   ↓
直接升级
   ↓
寒热病性

```
这个推理链缺少中间的证据约束。

## 二、八纲：最完整定义  
## 1. 八纲究竟是什么  
资料库中最明确的定义是：  
**表、里、阴、阳、寒、热、虚、实。**  
但是进一步阅读以后，不能把这八个概念看成八个完全同质、平行的指标。  
**第一层：病位**  
* 表  
* 里  
* 半表半里  
**第二层：病情/病性**  
* 阴  
* 阳  
* 寒  
* 热  
* 虚  
* 实  
因此，资料库体系实际上是在做：  
**病位 + 病情**  
而不是简单的“八个标签打分”。  
胡希恕对疾病观察的概括非常明确：病位反应“不出三个”，即表、里、半表半里；而每个病位又可以出现阴、阳两类不同反应。

## 三、“表、里、半表半里”的真正定义  
这是整个体系中最容易被现代解剖思维带偏的地方。  
## 1. 病位不是解剖病灶的位置  
资料库原文明确：  
病位是“病邪所反映的病位”，**不是病变所在的病位**。  
也就是说：  
```
解剖病灶在哪里
        ≠
辨证病位在哪里

```
病变可以在身体内部，但如果病邪的整体反应集中于表，仍可归为表证；反过来也一样。  
 胡希恕病位类方解.txt  
这实际上与你要求体系必须遵守的：  
**“现象所在 ≠ 机制所在”**  
高度一致。  
因此，“胃有病”不能直接推出“里证”，“皮肤有病”也不能直接推出“表证”。  
必须先问：  
**整个疾病反应主要落在哪一个病位层面？**  
   
⸻  
   
## 四、半表半里：必须单独处理，不能偷换概念  
资料库中胡希恕体系大量使用：  
表 半表半里 里  
并以此组织六经。  
胡希恕明确讲到疾病的病位反应有三个：表、里、半表半里；每一个病位又有阴阳。  
 (最完整版)胡希恕讲伤寒论.txt  
但是，人读冯世纶《经方临床带教实录》的专题讨论后必须保留一个**理论争议层**：  
* 一种体系把半表半里作为实际病位使用；  
* 另一种观点认为严格意义上的八纲只有表、里，半表半里属于后来的理论解释，是连接八纲与六经的概念。  
因此最终不能写成：  
“半表半里就是毫无争议的第三个八纲。”  
正确表达应是：  
**在胡希恕经方体系的实际辨证模型中，半表半里是核心操作性病位；但其作为八纲独立病位的理论地位，在资料库内部存在明确争议，因此不能把该理论地位标成无条件的A类定论。**  
另一方面，《解读张仲景医学》直接以《伤寒论》第148条“必有表，复有里……此为半在里半在外也”作为半表半里的重要文本依据。  
 解读张仲景医学_伤寒六经方证直解.txt  
所以：  
**操作层可以保留；理论本体论不能过度绝对化。**

## 五、阴阳：不是简单等于寒热  
这是前面最容易提取失真的地方。  
资料库定义：  
**阴 = 阴性证。阳 = 阳性证。**  
其理论基础不是“身体冷就是阴，热就是阳”，而是：  
**太过**  
机体功能变化较正常：  
* 亢进  
* 发扬  
* 兴奋  
这一类病征 → **阳证**  
**不及**  
机体功能变化较正常：  
* 衰退  
* 消沉  
* 抑制  
这一类病征 → **阴证**  
资料库原文明确如此定义。  
 胡希恕病位类方解.txt  
因此：  
```
阳 ≠ 单纯发热
阴 ≠ 单纯怕冷

```
而是：  
**阳/阴首先是对疾病状态相对于正常功能“太过/不及”的总括性分类。**  
   
⸻  
   
## 六、寒热：阴阳之下的具体性质轴  
资料库明确：  
寒 = 寒性证 热 = 热性证。  
进一步：  
寒为不及，所以属于阴；热为太过，所以属于阳。  
即：  
```
寒 → 阴
热 → 阳

```
但反向不能成立：  
```
阴 → 不一定寒
阳 → 不一定热

```
资料库甚至明确指出：  
可以有“不寒不热”的病，但不存在“不阴不阳”的病。  
这句话非常重要。  
 胡希恕病位类方解.txt  
所以最终判定逻辑不能写成：  
阴 = 寒，阳 = 热。  
必须写成：  
**寒是具有寒性特征的阴性表现；热是具有热性特征的阳性表现。阴阳范围比寒热更宽。**  
   
⸻  
   
## 七、虚实：最关键的定义不是“症状多少”  
资料库给出的定义非常明确：  
**虚指人虚，实指病实。**  
这是整个八纲里必须特别锁死的一条。  
## 虚  
不是简单：  
症状轻。  
而是：  
病未解，而人的精力已经有所不支，机体反应呈现虚衰状态。  
## 实  
也不是简单：  
症状很多。  
而是：  
病势仍进，而人的精力尚不虚，机体反应表现出充实的病征。  
原文定义见资料库。  
 胡希恕病位类方解.txt  
因此：  
```
虚 → 人的状态
实 → 病的状态

```
这意味着：  
**“人虚”与“病实”可以同时存在。**  
这也是为什么不能采用：  
症状重 = 实 症状少 = 虚  
这种粗糙算法。  
资料库医案进一步出现“久病人虚，而病势反而实大数”的结构，说明“虚”和“实”确实可以分别描述人体与疾病两侧。

## 十、六经六证的具体定义  
## ① 太阳病  
核心：  
**表阳证。**  
经典提纲：  
脉浮、头项强痛而恶寒。  
其基本结构是：  
```
病位：表
病性：阳
性质：偏热实

```
但不能反过来：  
“有发热 = 太阳。”  
因为发热可以出现在其他病位，甚至合病、并病。  
资料库中“身热恶风”的条文就是很典型的反例：身热不能单独把整个疾病定为某一经，因为同时存在表、少阳以及里热因素。  
 (最完整版)胡希恕讲伤寒论.txt  
   
⸻  
   
## ② 少阴病  
核心：  
**表阴证。**  
提纲：  
脉微细，但欲寐。  
资料库明确把太阳和少阴都放在**表位**：  
太阳是表阳；少阴是表阴。  
 (最完整版)胡希恕讲伤寒论.txt  
所以：  
```
表 + 阳 → 太阳
表 + 阴 → 少阴

```
这比单纯记“太阳发热、少阴怕冷”准确得多。  
   
⸻  
   
## ③ 阳明病  
核心：  
**里阳证。**  
经典概括：  
胃家实。  
其主要方向：  
```
病位：里
病性：阳
常见性质：热、实

```
典型实热表现可以包括：  
* 潮热  
* 大便难  
* 腹满  
* 热盛  
* 渴等  
但这些仍然是证候组成，不是“单一症状→阳明”的充分条件。  
资料库对大承气汤明确使用“里实热满、大便难”作为方证要点。

## ④ 太阴病  
核心：  
**里阴证。**  
基本方向：  
```
病位：里
病性：阴
常见性质：虚寒

```
因此太阴不能简单理解成：  
“腹泻就是太阴。”  
因为腹泻本身可以有寒热虚实不同结构。  
资料库甚至明确解释：  
“下利不渴”可作为太阴方向，而“燥而不渴”也可见于里寒；因为寒并不意味着一定有明显口渴。

## ⑤ 少阳病  
核心：  
**半表半里阳证。**  
经典提纲：  
口苦、咽干、目眩。  
实际辨证中最重要的是柴胡证结构，例如：  
* 胸胁苦满  
* 口苦  
* 咽干  
* 往来寒热  
* 心烦  
* 欲呕等  
但仍然不能把某一症状机械等同于少阳。  
例如：  
“身热恶风、颈项强、胁下满、手足温而渴”  
胡希恕解释为同时存在表、少阳以及里热因素，因此是复杂的三阳病结构，而不是看到“身热”就归阳明。

## ⑥ 厥阴病  
核心：  
**半表半里阴证。**  
经典提纲：

## 十一、六经不是静态标签，而是疾病状态  
这是人读后非常重要的结论。  
资料库明确强调：  
随着时间变化、正气与邪气斗争变化，证候也发生变化。  
例如：  
原来少阳，治疗以后出现明确渴证，可转入阳明。  
《解读张仲景医学》直接用“服柴胡汤已，渴者属阳明”说明这一点。  
所以：  
```
S(t1) ≠ S(t2)

```
疾病的六经状态必须允许随时间变化。  
这直接支持：  
**六经应该被建模为状态，而不是患者的永久身份。**  
   
⸻  
   
## 十二、合病、并病、传变  
因此六经还有时间结构。  
## 合病  
疾病开始时：  
两个或多个病位/六经同时出现。  
即：  
```
t0：
太阳 + 阳明

```
而不是先太阳、后来才阳明。  
## 并病  
前一病证尚未完全消失，后一病证已经出现：  
```
t1：
太阳
 ↓
t2：
太阳仍在 + 少阳出现

```
## 传变  
随着疾病演变：  
```
表 → 半表半里
表 → 里
半表半里 → 里
阴 → 阳
阳 → 阴

```
具体方向不能预先假定。  
胡希恕对少阴篇的解释尤其强调：太阳、少阴均属表，之后可以向里或半表半里变化；且阴阳两类疾病的传变方向存在常见趋势，但不是绝对封闭的。  
 (最完整版)胡希恕讲伤寒论.txt

## 十三、一个极重要的反例：症状不能单独决定病位  
这应该正式进入辨证引擎的“反例库”。  
《伤寒论》99条：

## 十四、寒热不能靠单一主观感觉直接判定  
这一点现在可以进一步固定下来。  
资料库中的大量材料显示：  
同一个表面现象，在不同结构下可以有不同解释。  
例如：  
“燥而不渴”  
并不自动等于热。  
胡希恕明确解释：  
* 燥而渴 → 可以是热实；  
* 燥而不渴 → 可以是寒实，因为寒导致津液不能正常产生。  
 胡希恕金匮要略文字版(1).txt  
所以：  
```
一个感觉
↓
不能直接
↓
跳到寒/热结论

```
必须看：  
病位 + 阴阳 + 其他证候组合 + 动态。  
这也是为什么“主观手足心热”不能单独作为“热证”的硬证据。

## 十五、虚实也不能靠表面症状判断

**虚实必须同时问“谁虚、谁实”。**

## 十七、第一毒：食毒  
资料库定义：  
多因摄生不善、饮食无节，使胃肠功能障碍、宿食不消、大便不通，废物不能及时排出，继而形成自身中毒。  
因此：  
```
饮食失常
 ↓
胃肠功能障碍
 ↓
食物/废物停滞
 ↓
宿食
 ↓
食毒

```
在仲景书中对应的核心语言之一就是：  
**宿食。**  
胡希恕病位类方解.txt  
资料库还列出：  
* 脉涩而大  
* 脉数而滑  
* 下利而不欲食  
* 宿食在上脘  
* 大便不通等  
作为不同场景中的证据。  
例如：  
“脉数而滑者，实也，此为有宿食。”  
“下利不欲食者，有宿食也。”  
胡希恕病位类方解.txt  
但必须注意：  
**这些是具体方证/条文中的证据，不等于所有食毒病例都必须同时具有这些表现。**

## 十九、第三毒：瘀血毒

其临床反应并不是千篇一律。

* 瘀血证候不是单一固定模式。

## 二十、三毒最重要的结构定位  
最终一定要写成：  
```
八纲：
    病位 + 病性

六经：
    八纲结构的六证化

三毒：
    病因/病理因素分析

```
因此：  
```
八纲 ≠ 六经 ≠ 三毒

```
但三者可以交叉。  
例如：  
```
里阳实
+
食毒

```
可以形成某些阳明实证结构。  
或者：  
```
半表半里阴
+
水毒
+
瘀血

```
也可能构成复杂方证。  
资料库实际医案中也反复出现：  
六经证候 + 水饮/瘀血等因素  
的复合结构。

## 二十一、“阴阳毒”绝对不能和“三毒”混为一谈  
这是这次最终整理必须单独加上的防错规则。  
《金匮要略》还有：  
阳毒 阴毒  
这与：  
食毒 水毒 瘀血毒  
**不是同一个“三毒”概念。**  
资料库对《金匮》“阴阳毒”的解释，是一种急性、凶险的咽喉肿痛类疾病：  
* 阳毒：面赤斑斑如锦纹、咽喉痛、唾脓血；  
* 阴毒：面目青、身痛如被杖、咽喉痛、不唾脓血。  
而且资料库明确指出，对“阴阳毒”究竟属于何病，历代注家说法并不一致。  
 中国汤液经方_下部_金匮要略传真.txt  
因此必须建立：  
```
“三毒理论”
    =
食毒 / 水毒 / 瘀血毒

“阴阳毒”
    =
《金匮要略》中的另一病名/病证概念

```
二者不能合并。

## 二十二、最终证据等级  
按照引擎 V1 证据标准，我建议最终这样分层：  
**A级：可以作为硬约束**  
1. 八纲基本定义：表、里、阴、阳、寒、热、虚、实。  
2. 阴阳的“太过/不及”定义。  
3. 寒属于阴、热属于阳，但阴不等于寒、阳不等于热。  
4. “虚指人虚，实指病实”。  
5. 病位是病邪反映的病位，不等同解剖病变位置。  
6. 六经作为六种证候类别，而非解剖经络。  
7. 三毒的核心对象：食、水、瘀血。  
例如虚实定义、阴阳寒热关系都有明确原文依据。  
 胡希恕病位类方解.txt  
**B级：高度重要，但存在解释层**  
例如：  
* 六经与八纲的具体对应；  
* 各六经的证候组织方式；  
* 某些“证→方”的归纳；  
* 某些病因与具体症状之间的解释。  
**C/D级：只能作为辅助**  
* 后世归纳出的简化口诀；  
* 医案中总结出的常见组合；  
* 单个临床经验规律。  
**E级/争议**  
尤其包括：  
* 半表半里的理论本体地位；  
* 厥阴提纲全部条文是否可以机械作为诊断硬门槛；  
* 某些条文文字校勘及后世解释；  
* “阴阳毒”的具体病种性质。

## 二十四、最终的“不可越界规则”  
如果把这次人读式整理真正用于引擎，我认为下面 **12 条**应该成为硬规则：  
**① 病位不是解剖位置**  
不能：  
病灶在里 → 里证。  
必须判断**病邪反应所在**。  
 胡希恕病位类方解.txt  
**② 单个症状不得直接决定八纲**  
```
发热 ≠ 阳明
怕冷 ≠ 少阴
腹泻 ≠ 太阴
口苦 ≠ 少阳

```
必须形成结构。  
**③ 阴阳不能简化成寒热**  
```
阴 ≠ 寒
阳 ≠ 热

```
只有：  
```
寒 → 阴
热 → 阳

```
胡希恕病位类方解.txt  
**④ 虚实必须区分对象**  
```
虚 → 人
实 → 病

```
不能把“症状重”直接等同“实”。  
**⑤ 六经不是六条解剖经络**  
六经是六种证候类别。  
**⑥ 六经不是永久身份**  
必须允许：  
```
太阳 → 少阳
少阳 → 阳明
少阴 → 太阴
……

```
以及合病、并病、传变。  
**⑦ 一个患者可以同时存在多个病位**  
“身热恶风、胁下满”就是明确反例。  
 (最完整版)胡希恕讲伤寒论.txt  
**⑧ 主观感觉不能单独充当寒热硬证据**  
尤其不能：  
“觉得热 → 热证成立。”  
必须寻找整个证候结构。  
**⑨ 未采集仍然是未知**  
例如：  
未问脉 ≠ 无脉数 ≠ 脉不数。  
**⑩ 三毒不能和六经同层处理**  
```
六经：证候状态
三毒：病因/病理因素

```
**⑪ “阴阳毒”不能归入三毒**  
这是独立防错项。  
**⑫ 半表半里的“操作定义”和“理论本体”必须分开**  
临床模型可以使用；  
理论上是否属于严格八纲第三病位，则保留争议。  
   
⸻  
   
## 二十五、最终总公式  
如果把整个资料库的这一部分压缩到最小而不损失结构，我认为现在最准确的是：  
```
疾病
│
├─ ① 八纲：确定“病位 + 病情”
│      │
│      ├─ 病位：
│      │    表 / 半表半里 / 里
│      │
│      └─ 病情：
│           阴 / 阳
│           寒 / 热
│           虚 / 实
│
├─ ② 六经：把上述结构组织成六类证
│      │
│      ├─ 表阳 → 太阳
│      ├─ 表阴 → 少阴
│      ├─ 里阳 → 阳明
│      ├─ 里阴 → 太阴
│      ├─ 半表半里阳 → 少阳
│      └─ 半表半里阴 → 厥阴
│
├─ ③ 时间维度
│      │
│      ├─ 合病
│      ├─ 并病
│      └─ 传变
│
└─ ④ 病因/病理因素分析
       │
       ├─ 食毒
       ├─ 水毒
       └─ 瘀血毒

```
**最终核心不是“给患者贴一个证型标签”，而是：**  
**先确定病邪反映的病位，再确定阴阳寒热虚实，再组织成六经证候；三毒作为另一层病因/病理因素进行交叉分析；整个判断必须保留时间演变、合病并病、证候竞争和未知项。**  
这已经比单纯的“八纲定义＋六经口诀＋三毒解释”完整一个层级，也更适合作为你之前确定的 **《辨证论治判定引擎 V1》基础定义层**。目前仍不应把存在争议的半表半里本体论、厥阴全部提纲等内容硬化为A类判据。
