## 二、结论：**算子不是组合机制。零形式并置才是默认。**

我上一轮的理论是「挟/兼/而/因致四个算子 ＝ 组合的核心语法」。
**数据当场推翻它：90.1% 的证元根本没有算子，而其中 83.6% 仍然是多成分组合。**

正确形态是：

> **组合的默认形式是【零形式并置】——成分靠各自的槽位就把关系表达完了，不需要连接词。
> 显式算子是【标记性的】，只在槽位语法表达不了那种关系时才出现。**

这个修正**比原理论更简单**，而且**不需要我方发明任何东西**——
它就是汉语的定中／主谓／对举结构，胡老直接在用。**合纲领七：不要重新理论化。**

## 三、四种槽位语法（覆盖 61 条无算子多成分证元）

### 语法① `[正气载体] + [虚实态]` —— 8 例
> 营卫失调(L476)｜营卫不和(L499,L1390)｜津液本虚(L553)｜**胃气沉衰(L622)**｜心气不足(L849)

**这正是 L6 津液胃气轴的原生语法。**㉒批立 L6 轴时是从条文推的；
现在在**胡老自己的病历判断句里**，它是**出现频次最高的单一句式**。
—— 上级关于「津液胃气是底层量而非并列维度」的判断，在**病历用语层**再次得证。

### 语法② `[病位] + [虚实态] (+[寒热])` —— 6 例
> 阳虚表证(L864)｜虚寒表证(L1290)｜表虚里寒之证(L679)｜里实热盛(L1749)｜里实热胃不和(L1819)

### 语法③ `[病理产物] + [动向]` —— 4 例
> 寒饮内停(L1064)｜水饮内停(L1229)｜水饮上犯(L965)｜寒饮上扰心神(L980)

**动向不需要"因致"也能表达**——「内停」「上犯」「上扰」「外溢」「外郁」「流注」本身就是动向成分。
上一轮我把「气上冲」当成必须由算子承载的东西，**这是错的**：动向是一个成分槽，不是一个算子。

### 语法④ `[病位对举]` —— 多例
> 外寒里热(L1211)｜外寒里饮(L1250)｜外内皆热(L1365)｜外邪里湿(L1543)｜寒饮内盛外溢于表(L1050)

**对举本身就是关系。**「外…里…」的并列，不需要任何连接词就已经声明了"两层同时在场"。

## 四、那么算子在什么时候才出现？（8 例逐条）

| 算子 | 例 | 为什么槽位语法表达不了 |
|---|---|---|
| **挟** | 表虚**挟**腹肌不和(L514) | 后项「腹肌不和」自身已是完整的[病位+虚实态]，**塞不进前项的槽**，须用算子挂上 |
| **而** | 表虚**而**里热(L937)｜表虚血虚**而**水湿内停(L893) | **跨层并存**：表层与里层各自成立，对举不足以表示（对举是同一层的两侧） |
| **因致** | 营卫不和汗出上虚**因致**气上冲逆(L499) | **因果方向**：并置无法区分谁致谁，须显式锁定箭头 |
| **兼** | 少阳阳明合病**兼**瘀血阻络 | **合方声明**：兼夹项有独立基础方 |

**统一表述**：
> **算子 ＝ 槽位语法溢出时的补充标记。**
> 溢出有四种：①后项自身是完整证元(挟) ②跨层并存(而) ③因果方向(因致) ④独立基础方(兼)。
> **不溢出时不用算子——这占 90.1%。**

## 五、这对引擎意味着什么（**规格，未挂载**）

**表示形式**应为：

```
证元 ::= 成分序列 [算子 成分序列]*
成分 ::= <槽:值>   槽 ∈ {病位, 正气载体, 虚实态, 寒热, 病理产物, 动向}
默认关系 ::= 并置（由槽位组合自明）
算子 ::= 挟|而|因致|兼   —— 仅在四种溢出情形使用
```

**上一轮我要 Code 做的「关系算子表」是次要工程；真正的地基是【六槽位表】。**
这个更正必须写进交接包，否则 Code 会照旧规格建一个只覆盖 10% 情形的算子库。

## 六、本文自身的诚实边界（视角㉕/㉚）

1. **12 条"单成分"是切分器覆盖不足，不是真单成分**：
   `肝郁水停`(肝郁+水停)、`寒饮停胃`(寒饮+停+胃)、`寒饮困滞经筋失养`、`久热伤阴`
   ——切分词表缺"郁/停胃/困滞/失养/伤阴"等。**故 83.6% 是下界，真值更高。**
2. **15 例未抽出**（13.5%）系块边界14行截断，**未做人工补捞**——
   宁可报缺，不猜（协议4）。
3. **同义未归并**：寒饮/水饮/停饮/水气 未合并、内停/内盛 未合并。
   **归并属判据结构裁决，须另行取证**（㉒批纪律），本工具不代做。
4. **抽取器自查已修一处假阳性**：首版把「太阳／少阳／阳明」里的"阳"字计为
   正气载体·阳（虚报 16 次）。已在 `split_comp` 中先屏蔽六经名再切分。
   **结构性结论（61条/83.6%）不受影响**，因该错只影响成分频次，不影响成分个数是否≥2。
   —— 记此，是因为视角㉑要求工具的错要和结论一起报，不能只报修好的版本。
5. **本文只证明"表示能力"，不证明"覆盖能力"**：
   它说明胡老的判断句可以被六槽位无损表示；**没有**说明由此能选对方。
   后者要等 230 方签名化 + 回归对照，**不得提前宣称**。
