## 本目录记录的一次自我否证

上一轮我提出的理论是「挟／兼／而／因致四个关系算子 ＝ 组合的核心语法」。
全量统计当场推翻：**功能描述型 81 条中，有显式算子的只有 8 条（9.9%）**，
而无算子的 73 条里 **61 条（83.6%）仍然是多成分组合**。

修正后的形态更简单，且不需要我方发明任何东西：
> **默认是零形式并置（槽位自明），算子只是槽位语法溢出时的补充标记（四种溢出情形）。**

**真正的地基是【六槽位表】，不是【算子表】。** 交接给 Code 的规格须据此更正，
否则会建成一个只覆盖 10% 情形的算子库。
