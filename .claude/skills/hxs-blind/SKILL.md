# 盲测隔离（hxs-blind）

## 两次事故，同一个形状

| 批 | 事故 |
|---|---|
| **98批** | 五例盲测**全部作废**。T1／T2 的答案就在**执行核 1.6 表**里（「浮肿→越婢汤类」「腰膝酸软→肾气丸」，以本案主症为键）；T4／T5／T1 的答案在**引擎呈现校准**里。⇒ `holdout/` 之**全部历史判分**「盲」不成立——51% 的案与引擎呈现校准高度重合。 |
| **115批** | V8 v2 末尾 20 组边界盲测：**协议头 L20560，金标准 20 条答案 L20598**——**同一个文件**，中间只隔一句「禁读」。 |

两次的共同点：**隔离是靠一句文本承诺实现的**，而读取是靠工具实现的。
**承诺挡不住 `open()`。** 98批 之后 `holdout/` 全部作废，115批 之后金标准迁出为
`V8/blind/金标准_禁入执行上下文.md`，这才是物理分档。

⛔ 所以本协议的第一条不是「注意不要读」，是：**答案不许和题目在同一个可读对象里。**

## 四条硬纪律

### ① 金标准物理分档

```
V8/blind/病例区_20组.md            ← 题目。Solver 可读
V8/blind/金标准_禁入执行上下文.md    ← 答案。⛔ 只供 Evaluator
```

- 题与答**必须是两个文件**，不是同一文件的两段。
- 新建盲测一律照此分档；**不得**以「下面是答案，判题时请勿阅读」这种行内分隔代替。
- 分档状态登记在 `tools/manifest.py`（MANUAL 档）并注明分档纪律。

### ② 出题前，答案反查引擎（闸门9⑬）

出题之前，把**答案里的每个关键结论**取二字串／三字串，回查引擎与执行核：

```bash
S=.claude/skills/hxs-crossbook/scripts
grep -n "越婢" V8/hxs_engine_v8_full_v2.md hxs_engine_执行核.md
grep -n "肾气丸" V8/hxs_engine_v8_full_v2.md hxs_engine_执行核.md
```

命中 ⇒ **该题作废重出**。理由：引擎里已经有以本案主症为键的直达映射，
Solver 答对它不需要辨证，**这道题测不到任何东西**。

⚠ 二字串而非整句。98批 漏掉是因为只查了整句，而引擎里写的是表格化的短形式。

### ③ 执行上下文白名单

判题／出方时**可读**的只有执行路径上的东西。以下一律**禁入执行上下文**：

```
⛔ V8/blind/金标准_禁入执行上下文.md
⛔ holdout/            （98批后全部作废，不再作盲测源）
⛔ test_测试资产.md     （示范案、W错案、守卫、测试数字，全部禁读禁引）
⛔ G守卫 25 处          （留 03_方证库原位，仅作回归测试，⛔ 禁作判据）
```

白名单是**列举式**的：没被列进可读清单的，默认不可读。
⛔ 不要用黑名单——黑名单漏一项就等于没有。

### ④ 读到禁读区即声明作废

如果在判题过程中**已经**读到了禁读内容（包括：工具返回里夹带、上文早已载入、
grep 结果里露出一行），处理方式只有一个：

> **立刻停止，声明本次盲测作废，说明是哪一处泄漏，重出题。**

⛔ 不得「我读到了但我没用它」。**没有办法证明没用。**
本工程的立场一贯是：不可证伪的自辩不算证据（与 M4 之 9:0 被废掉同理）。

## 成绩怎么报

98批 已作废的口径：**98.0%（未遮盖）不再是成功指标。**

现行成功指标（用户诊断信定稿）：

```
独立复现率 ｜ 遮答案准确率 ｜ 反例鲁棒性 ｜ 未知纪律 ｜ 可追溯性 ｜ 反事实稳定性
```

报成绩时同时必须报：

| 必报项 | 为什么 |
|---|---|
| 题目来源与**分档证据**（两个文件路径） | 否则「盲」未证 |
| ②之**反查记录**（查了哪些串、命中几处） | 否则不能排除直达映射 |
| **未知计数** | ⛔ `unknown` 不进分子（协议51：未采 ≠ 阴性） |
| **分母怎么来的** | 见 `hxs-gates` 分母纪律；分母须由枚举产生 |

⛔ **不得以「测试全绿」或「准确率 X%」作为完成证明。**
测试只能证明**已经编码进去的错误模型**没有违反自己；
它不能证明**遗漏的语义条件**不存在。

## 出题时顺带该想的一件事

一道好的盲测题，**答错的方式应该多于一种**。
如果这道题只要认出主症就能答对，那它测的是查表，不是辨证——
那正是 98批 五例全废的实质，而不只是「答案泄漏」这个表面原因。

⇒ 出题后自检一句：**这道题如果把方名全部遮掉，Solver 还需要做哪几步判断？**
答案若是「零步」，题作废。
