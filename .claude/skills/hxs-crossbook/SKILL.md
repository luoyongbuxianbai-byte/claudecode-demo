# 同段异写对照检索（hxs-crossbook）

## 为什么

111批 的实测：上级给的 20 条引文，Code 报「未直接核到」。
逐条人读之后——**14 条本不是引书**（是行文／标签），**6 条是真引文，改用异写检索后全部核到。**

漏掉的原因不是语料缺，是**措辞不同**：

| 一本里写 | 另一本里写 |
|---|---|
| 「不是较正常太过」 | 「而其改变不是较正常为太过」 |
| 「为太过／为不及」 | 「若泛言」「亦必阳」「即称之为」 |

⇒ 111批 立为常设法：**凡检索总论级内容，须用同段异写对照，不得只用单书措辞。**

这条法和闸门9⑦（不得以检索宣称全库无）是一对：
⑦说「检索不能证明无」，本法说「**那就至少把检索做对**」。

## 跑法

```bash
S=.claude/skills/hxs-crossbook/scripts

python3 $S/crossbook.py 脉缓                     # 自动展开异写族，十二书逐书报数
python3 $S/crossbook.py 脉缓 缓脉 脉逐渐缓         # 追加人工异写（脚本不猜近义词）
python3 $S/crossbook.py --pair 缓 胃气            # 双向式：缓…胃气 与 胃气…缓 各查
python3 $S/crossbook.py 脉数 --ctx 80 --max 5     # 每书每式打 5 处，各带 80 字
```

脚本经 `tools/corpus_guard.load_one/load_books` 读书（闸门9 第六款统一入口），
任一本缺失即中止，**不静默跳过**。

## 异写族的四类变形

脚本**只做能机械解释的三类**；第四类它不做，必须人工补。

| 类 | 脚本 | 例 |
|---|---|---|
| 词序变化 | ✅ 自动（二字词倒装） | `脉缓` ↔ `缓脉` |
| 修饰词插入 | ✅ 自动（`A.{1,3}B`） | `脉缓` ↔ `脉浮缓` ↔ `脉按之缓弱` |
| 双向式 | ✅ `--pair` | `缓…胃气` ／ `胃气…缓` |
| **近义表达** | ⛔ **人工** | `阳衰` ↔ `亡阳` ↔ `阳气衰` ↔ `阳虚` |

⛔ 近义表达脚本故意不猜。自动生成的近义词会把**你的联想**混进**语料的事实**里，
而这一步正是本工程反复出事的地方。近义词从哪来？——从 `hxs-reading` 的通读里来。

## 逐书报数，不合并

脚本输出是一张 12 行的表。**不要把它加总成一个数。**

合并计数会把「只在一本里有」读成「普遍如此」，而本工程十二书的性质完全不同：
两本是 `hu_lecture`（讲伤寒／讲金匮），九本是 `editor_compiled`，C卷 是 `uncertain`。
**一个说法在讲课本里有、在整理本里没有**，和反过来，是两个完全不同的结论（见 `hxs-gates` GATE_4）。

## 结果怎么用

### 查到了

每处命中带 `〔A·<书>·<字位〕`。⛔ 拿它当证据之前还要过两关：

1. **取证半径**（GATE_1）：命中点只是入口，须读到**同一解释单元结束**，
   尤其注解本的胡老评议常在条文之后数百字。**§214 就是这么漏的。**
2. **归因**（GATE_4）：命中在哪本书，决定你能不能说「胡老说」。C卷 = `uncertain`。

### 没查到

⛔ **「没查到」只是一个检索结果，不是一个结论。** 可以写的只有：

> 以下检索式族在十二书中未命中：`<原样抄出检索式>`

不可以写的：「胡老没说过」「全库无此规则」「原文未给入口」。

122批 就是在这里出的事：险些发布「原文未给可观察入口·禁执行」，
而入口在〔讲金匮·85483〕「时时振寒／吐如米粥」。
⇒ **立法：凡判「原文未给可观察入口」，须先全书检索并记检索式。**

### 存档要求

GATE_2 的 `record_required`：**每个否定性检索须保存实际使用之 query family，不得只留结论。**
只留结论，等于把「我没找到」写成了「它不存在」，而后者无法被任何人复核。

抄进证据册的最小格式：

```
检索式族（<n> 式）：
  - 原词        <pat>
  - 词序倒装    <pat>
  - 修饰词插入  <pat>
  - 人工补·近义 <pat>
逐书命中：C卷 <n>｜讲伤寒 <n>｜…（12 项全列，不合并）
命中之书：<k> / 12
```
