# 通读协议（hxs-reading）

## 为什么要有这条协议

检索能告诉你**你问的那个词在哪里**。它不能告诉你**你没想到要问的那句话在哪里**。

⛔⛔ **126W 订正（上级实读所指）**：本节原写「本工程的失败史**全部是后一种**」——
⭐ **不成立**。下表四例中，**126D 是检索被截断**、**126C 是资产分叉**，
⛔ **二者都不是「没想到要问什么」**。⇒ 改为：**下列四例各有其根因，⛔ 不共用一条。**

| 批次 | 事故 | 根因 |
|---|---|---|
| 122批 | FLIP-02 险些发布「原文未给可观察入口·禁执行」，而入口就在〔讲金匮·85483〕「时时振寒／吐如米粥」 | 判「无」之前没做全书检索 |
| 125批 | §214 被当成反例用了一整批，而胡老在条文之后约 400 字处写「**其中必有错乱，故不释**」 | 只读条文不读注——**第三次**取证半径太小 |
| 126C | 七组翻转对报「无锚」，锚一直在 `tools/fanzhuandui.py::PAIRS` | 没读自己的资产，只读了手边那张表 |
| 126D | 起草报告时写「STEP 0–11 不在本仓库，我搜过」——它在 `指令/115批…md` L1830 | ⭐ `grep … \| head -10` **把结果截断了**，然后**从被截断的列表得出全称否定** |

⛔ **126W 订正**：原写「**四次是同一个动作的四次失败**」⇒ **撤回该归并**。
⭐ 四例之**共同后果**确是「在没有读完的地方断言那里没有东西」，
⛔ **但其根因分四类**：①判无之前未检索（122批）②取证半径太小（125批）
③未读自己的资产（126C·资产分叉）④**检索结果被截断而据以作全称否定**（126D）。
⇒ ⭐ **修复手段各不相同** ⇒ ⛔ 不得以一句话覆盖。

## ⛔ 落笔前那一次核（本协议最便宜、也最有效的一条）

> **凡将写下否定性断言（「不存在」「没有」「未见」「查不到」），
> 落笔之前必须再做一次【不带任何截断参数】的独立检索。**

126D 那次就死在一个 `head -10` 上。所以具体地说：

```bash
# ⛔ 不要这样得出「不存在」
grep -rln "X" . | head -10

# ✅ 要这样
grep -rc "X" -r .            # 先看总数
grep -rln "X" .              # 再看完整文件列表，不截断
```

`head` / `--max` / `limit` / `head_limit` 这类参数，是一个**与语义完全无关**的截断面。
它在「我要看几个例子」时是对的，在「我要证明没有」时**是致命的**。

⇒ 记为 **A2 `tool_output_truncation`**，与 A1（原文取证半径不足）**分列**——
二者都是 A 类，但一个发生在读原文时，一个发生在读工具输出时，**四闸原本只盖到前者。**

⛔ 所以本协议的核心不是「多读一点」，是**把「我读了多少」变成一个必须报出的数**。
不报这个数，「我查过了」这句话没有内容。

## 规程

### 第一步：先声明读取计划，再动手

在读任何东西之前，写出三样：

```
读取目的：<要判什么？这次读完要能回答哪个具体问题？>
读取区间：<文件／书名> 第 <a>–<b> 行（或 字位 <a>–<b>）
区间依据：<为什么是这一段？边界怎么定的？>
```

区间依据这一栏最容易糊弄。**「感觉够了」不是依据。** 合法的依据只有：

- 同条／同段／**同一解释单元**结束（见下「解释单元边界」）
- 整个文件
- 目录／章节结构给出的自然边界

⛔ **「±400 字」不是依据。** §214 就死在这里：胡老的裁决恰在窗缘之外。
固定字符窗是一个**与语义无关**的量，它碰巧够用的那些次，是运气。

## ⛔⛔ 两条执行位置（126V 挂接——⛔ 不是「注意事项」，是**动作**）

> 上级 126V 令五：「把『**发现错误后更新所有当前消费者**』和
> 『**提出排除判断前检查反向蕴涵**』放到**实际执行位置**。」

### 执行位置一：**撤回一句话时，同一动作内更新它的全部消费者**

⛔ **「在报告里写了『撤回』」不算撤回。** 126U 之实例：
报告与 015 读记撤了「作者从未给出独立津液测度」，⛔ 而 P-02 §3.2、§六仍以它为现行结论
⇒ 下一批读证据册就会**再次继承已撤结论**。

**动作**（⛔ 缺一不可）：

```bash
# ① 原句
grep -rn "<被撤之原句片段>" evidence/ reports/ rules/ .claude/
# ② 依赖该句之结论／表格：查撤回后**结论会变**的那几处，⛔ 不是只查字面
grep -rn "<该结论之关键词>" evidence/ reports/ rules/
# ③ 索引：rules/report_index_v0.json 之 proposition / counter / note 三栏都要看
python3 tools/report_index.py            # 重渲染
```
⇒ ⭐ 提交时**列出「哪些当前判断发生改变」**，⛔ 不是列「改了哪些文件」。
⇒ ⭐ 历史判断**可留存**，但须**明标为历史**；⛔ 当前结论不得继续引用它。

### 执行位置二：**写排除判断前，先写出它依赖的蕴涵方向**

⛔ 凡将要写「**没有 X**」「**排除了 Y**」「**不成立**」之前，先在草稿里补一行：

```
我依赖的蕴涵是：  A → B
我要用的是：      ¬B → ¬A        ← 这是逆否
或                ¬A → ¬B        ← ⛔⛔ 这是否定前件，**非法**
```

⛔⛔ **126W 前置一步（上级实读所指）**：**写下 `A → B` 之前，先核它是哪一种**——
⛔ **经验性指示不因写成箭头就获得严格逻辑性质。**

| 该「箭头」之性质 | ⭐ 逆否是否可用 |
|---|---|
| **严格蕴涵**（定义、分类之穷尽划分） | ⭐ **可用** |
| **经验支持**（「尺中迟 ⇒ 荣气不足」这类**指示关系**） | ⚠ ⭐ **逆否只在【该判据能检出全部该状态】时才可用** ⇒ ⛔ 该前提未证时，**阴性之证据力未知** |
| **作者之解释**（「血少不充于脉，脉就迟」） | ⚠ ⭐ **可作【带归属之假设】**：写成「**若作者之解释成立，则…**」，用来**检查作者体系内部之推论是否自洽**。<br>⛔⛔ **不可**当作**已验证之医学事实**，⛔ 不可用来支持关于患者的结论。<br>⛔ 126X 订正：原文作「⛔ 不可用作逻辑前提」——**过宽**（上级 126X）。 |

⚠ ⭐ 126U 之实例属**第二类**：我不但用了否定前件，
⛔ **即使改成逆否（不虚 ⇒ 不迟），也仍须先证「迟能检出全部虚」** ⇒ ⛔ 该前提至今未证。

⚠ 126U 之实例：原文给「**尺中迟／微 ⇒ 荣气不足／里虚**」（指示关系），
⛔ 我用它推「**不迟不微 ⇒ 无津液损伤**」——**否定前件**。
⚠ 并须另问一句：**该判据能否检出全部该状态？** 若未证，则**阴性结果之证据力未知**。

⛔ **三条常见非法形式**（⛔ 逐条对照）：

| 形式 | 例 |
|---|---|
| **否定前件** | 迟⇒虚，故不迟⇒不虚 |
| **未记当无**（协议51） | 条文未言曾下之，故未经误治 |
| **未得当已否** | 不足以支持该组合 ⇒ 写成「该组合不成立」 |

## ⭐⭐ 边界检查是**两项**，⛔ 不是一项

```bash
python3 tools/unit_bounds.py 讲伤寒 --anchor 161934   # 这个锚落在哪一条？该条真边界？
python3 tools/unit_bounds.py 讲伤寒 --range 122227 123518   # 我的区间与条目对齐吗？
```

| 检查 | 问什么 | ⛔ 它**不能**证明什么 |
|---|---|---|
| **① 精确锚** | 这个字位上是不是那句话？ | ⛔ 不证明**语境读全** |
| **② 完整语境** | 我的区间是不是一个完整解释单元？ | ⛔ 不证明**我真的逐字读过** |

⛔⛔ **二者皆过，仍须人读**——`unit_bounds` **只认「第N条」形态**，
　⭐ 实测假阳性：**§24 在 OCR 本作「24、太阳病……」**〔29943〕⇒ 工具漏检；
　⛔ **讲金匮等书无此标记 ⇒ 测不出**（茯苓条之边界 107067 是**人读定位**的）。

### 第二步：**按问题形态选路**（⛔ 126W 改：原作「顺序读，不先 grep」，与本 skill 开头冲突）

⛔⛔ **两句不能并存**：description 已写「检索可以发现问题，通读也可以验证问题，
**二者之间没有固定分工**」，⛔ 而此处原写「顺序读，**不先** grep」⇒ **126W 就地统一**。

| 问题形态 | ⭐ 该走哪条 |
|---|---|
| **「这一段讲了什么」「作者如何判断」** | ⭐ **顺序读完整解释单元**。⛔ 检索之命中不能代替它 |
| **「某句是否存在」「某锚是否属实」「某处怎么说」** | ⭐ **直接检索定位再读该单元**。⛔ 不必先通读，⛔ 不必先定分母 |
| **「全库有没有 X」** | ⭐ 走 `hxs-crossbook` 之异写族框架，⛔ 并受覆盖度约束（见第五步） |
| **「原始载体上这个字是什么」** | ⭐ 走**校勘**路（见本 skill 末「校勘时读原始文件」一节） |

⚠ ⭐ **仍然成立的那一半**：**若目的是「读懂这一段」，先 grep 会让你只看到你已经会问的东西，
然后你会以为你读过了。** ⇒ ⛔ 故第一行之「顺序读」在**该形态下**仍是硬要求。

grep 的合法位置（⭐ **126U 依上级裁决扩充；⛔ 原文只列两条，与后续裁决冲突**）：
1. **顺序读之后**，用来回查某个你已经在正文里见过的说法的其他出处；
2. 在 `hxs-crossbook` 的异写族框架下做否定性检索（那是另一回事，有它自己的纪律）；
3. ⭐ **核查一个已经明确的候选**（「某条是否存在」「某处怎么说」「某锚是否属实」）——
   ⛔ **不必先定分母**。上级 126U：「**不必等『全库分母确定』才能核查一个明确候选**；
   分母主要约束**覆盖率、频率和全称结论**。」
   ⚠ 实例：126S 之 T-126Q-1 结案｜126T 之 126B 追因｜126U 之 §91 定向核查；
4. ⭐ **定位**（找条号、找方名、找某段之偏移），⛔ 只要不把定位结果当成「已读该段」。

⛔ **仍然禁止者**：以 grep 之命中**代替**对该解释单元之人读；
⛔ 以 grep 之未命中作**全称否定**（闸门9⑦）。

如果任务看起来太大而只能抽样读——**那就明说是抽样**，并在第四步把未读比例报出来。
抽样读是允许的；**抽样读之后说「全库没有」是不允许的**（闸门9⑦）。

### 第三步：逐段记锚

每读完一个解释单元，写一行：

```
〔<书名>·<字位>〕<这一单元实际说了什么——用它自己的话，不要用你的概括>
```

用它自己的话，是因为概括会把限定词吃掉。本工程已有两次实例：
「C卷与传真系**同族**」原本只有「栏目结构相似」的证据，概括了一次就变成断言；
「63 组候选」在五份报告里被引用，而它**从来不存在**。
⛔⛔ **126U 订正**：原文作「**限定词是在概括里丢的，不是在推理里丢的**」——
⭐ 上级 126U 驳：**这是无依据的排他归因；两处都可能丢。**
⇒ ⭐ **改为**：**限定词在概括里会丢，在推理里也会丢。**
⚠ 本工程两类实例俱在：
· **概括处丢**：「C卷与传真系同族」｜「63 组候选」；
· **推理处丢**：126R 以「有热∧不渴」冒充「阳明∧不渴」（前提域丢失）｜
  126T 之 T-04 把「A∧¬B」当作「B→A」之反例（蕴涵方向丢失）｜
  126U 之「渴＋小便不利」由「不足以支持」写成「不成立」（模态丢失）。
⇒ ⛔ 故**两处都要查**：写完概括回看原文；写完推理回看**前提域、方向与模态**。

### 第四步：读毕报三数

```
已读区间：<行/字位 a–b>，共 <N> 行 / <M> 字
未读区间：<列出来，不要写「其余」>
未读比例：<N_unread / N_total = xx%>
```

⛔ **「工具请求过全文」不等于「已人读理解」。**
判定标准很简单：**第三步里有没有逐段的内容记述？**

⛔⛔ **126U 订正（上级裁决）**：没有逐段记述，只能判为
**「缺少可审计的阅读记录」**，⛔ **不能判为「没读过」**——
**记录缺失不证明认知事件不存在。**

⇒ ⭐ 对工程之实际后果**不变**：无记录者**不得据以作断言、不得计入覆盖率**。
⇒ ⛔ 但**不得**据此指控他人（或自己）「没读」，⛔ 亦不得据此推断当时未处理过某句。
⚠ 这一条在 `rules/failure_classes_v0.json::A4` 之 `caveat_126T` 里有对应：
「『记录中出现过』不等于『执行者当时已经完整处理过』」——**反向亦然**。

### 第五步：断言时带上读取状态

做出裁决时，裁决旁边必须能看到它是在什么阅读覆盖度下做出的：

- 覆盖度 100% ⇒ 只可作「**已审范围内未见 X**」之说明
  ⛔ **读完也不自动保证语义无遗漏**（异写、代词、简称、OCR 误字皆可致漏）——
  与 `hxs-crossbook`／闸门9⑦ 之否定纪律一致：**通读提高覆盖，不产生全称否定权**
- 覆盖度 < 100% ⇒ 只可作「**已读区间内无 X**」，并列出未读区间
- 未读比例未知 ⇒ ⛔ 不得作**全称**否定性断言（「全库无 X」「作者从未 Y」）

⛔⛔ **126W 收紧（上级实读所指：原文过宽）**：原写「⛔ 不得作**任何**否定性断言」。
⭐ **核实某段确切文字，不要求先知道全库阅读比例。**

| 否定性断言之类型 | 是否须先知覆盖度 |
|---|---|
| **全称**：「全库无 X」「作者**从未** Y」 | ⭐⭐ **须**（且须分母） |
| **定位性**：「**§50 这一段里没有提治疗史**」 | ⛔ **不须**——⭐ 读完该单元即可断，⚠ 但须写明**论域是该单元** |
| **属性性**：「**这三种页码形态在讲伤寒未命中**」 | ⛔ **不须**——⭐ 但须写明**已试之形态**，⛔ 不得说成「无任何线索」 |

⚠ ⭐ 126U 之两处实例正好一反一正：
⛔ 「讲伤寒**不存在任何**页码线索」＝ 越界（由三形态推全部形态）；
⭐ 「已试三形态未命中」＝ 合格。

## 解释单元边界

「读到哪里算读完一段」这件事，两类书不同：

**注解本**（C卷／解读／传真系系）：
`《伤寒论》第N条`｜`《金匮要略…》第N条`｜`【栏目】`｜`注解：`｜`按：`

**讲课本**（讲伤寒／讲金匮）：
`第N条`｜`N、`｜页眉 `胡希恕《…》讲义-龙门课栈N/732`

⚠ 注解本的要害在于：**条文与胡老的裁决是分开的两块**，中间常隔几百字。
只读到条文末尾就停，等于只读了被评议的对象，没读评议。**§214 就是这么漏的。**

⛔ 若边界无法确定 ⇒ 记 `context_complete = unknown`，**该材料不得进入决定性证据**。
`unknown` 不是「大概没问题」，是「不能用」。

## 读原著时的统一入口

⛔⛔ **126W 拆两路（上级实读所指：原文「一律」会阻碍已授权之原始 OCR 校勘）**：

| 用途 | ⭐ 读法 | 理由 |
|---|---|---|
| **常规阅读、取锚、引用** | ⭐ **一律经 `corpus_guard`** | 字位锚以**清洗版本**为准；⛔ 直接 `open()` 会得到与全仓不一致之偏移 |
| **校勘（`ST-3`）** | ⭐⭐ **必须读原始文件** | ⭐ 校勘之对象正是**清洗前之字形与残迹**；⛔ 清洗器会删掉要校的东西 |

⭐ **校勘时之硬要求**（⛔ 缺一不可）：
1. ⭐ 用 `tools/anchor_provenance.py` 建 `清洗字位 → 原始行段` 之映射，⛔ **不徒手对**；
2. ⭐ 记 `source_file` ＋ `cleaned_len` ＋ `cleaned_sha12`，⛔ 防日后同字位指向不同文本；
3. ⛔ **原始文本不可覆盖**；校读意见、依据、未决异文**另存**（`rules/collation_v0.json`）；
4. ⛔ 清洗与医学解释**分开**——⛔ 不得因某字「讲不通」就改字。

# ⭐⭐⭐ 通读之五问（126AH 立｜**全文以附编四为准**）

> **纲领**：`evidence/研究纲领_附编四_批判性通读与独立纠错_v1.0.md`（⭐ 纲领地位）
> ⛔⛔ **按【解释单元】识别需要处理的问题，⛔ 不要求每条填写五份表格。**
> ⭐ 上级 126AH 原话：「不把四问改为**每条必须填的机械表**。」

| 问 | 阅读时具体做什么 |
|---|---|
| **① 这句话实际断言了什么？** | 分清**观察／定义／解释／建议／预期后果／已发生的结果**；把**否定、条件和程度**一起保留 |
| **② 它承接什么、限制什么？** | 查「**反、仍、复、若、或、但、兼、遂、必**」在本句中的关系；识别**倒装、省略、回指、对举、篇章切换** |
| **③ 作者凭什么这样解释？** | 分清**本条文字／跨条互参／方药反推／版本依据／临床自述** —— ⛔ **不能混成一种证据** |
| **④ 还有什么读法？** | **先查既有研究**（`prior_work.py`，只用于定位）；比较各读法**需要哪些前提、能解释什么、在哪些材料上失败** |
| **⑤ 这会改变什么研究结论？** | 明确是否改变**状态判断／分野项／用药资格／禁忌／次序／剂量／反馈判断**；**没有改变的，⛔ 不强造新结论** |

## ⭐ 几个字须**保留关系**，⛔ 不孤立收词

- **反** —— 相对于**什么预期**？该预期来自**本条、常例，还是讲解者的理论**？
- **必** —— **什么前提下**的必然？是**定义要求／作者经验概括／条件性预言**？
  ⛔⛔ **「必」不能直接编码成无条件硬规则**（126AH 上级明示）。
- **兼** —— **谁兼什么**？**两种表现并存／两个状态并存／兼用治疗**？⛔ 「兼」本身**不证明上下游因果**。
- **仍、复、遂** —— 须核**时序与前态**。
- **宜、与、可与、主之、当、应** —— 谁在建议什么、据哪些已知条件、**是否还要求补察**？
  ⛔⛔ **不先造一张全书通用强度表**；⭐ 胡老对它们的解释**也须逐处核验**。
  ⚠ 「与」**不能单凭一字决定证据强弱**。
- **愈、好、不差、仍** —— **哪项**改善、**何时**改善、**还有什么残留**？⛔ 不把局部结果写成全病痊愈。

## ⭐ 医案同法

分别保存：**患者报告／检查所见／明确阴性／诊断解释／既往治疗／当前处置／用量及制备／时序／结局**。
⛔ **未记症状不补阳性，也不补阴性。** ⭐ 主观感受**是**可记录信息；
⚠ 作者给出的**机制名称**⛔ 不因写得明确就成为实测事实。
⭐ 「我遇到过」是**经验陈述**；⛔ **实际行动不自动证明其理由正确**。

## ⭐⭐ 证据身份五类（⛔ **来源类型，不是从低到高的排行榜**）

`条文明记`｜`作者释义`｜`跨条援引`｜`由方推断`｜`临床自述`

⛔ 上级 126AH 明示：「**它们是来源类型，不是从低到高的固定排行榜。**」
⇒ ⛔ 不得因某项属「临床自述」就自动降权，⛔ 也不得因属「条文明记」就自动免检。

## ⛔⛔ 校改之证据要求，与「恢复条件」不同

⭐ 126AH 实例对照：
- **§98**：作者**提出倒装**以**界定条件** ⇒ 改变的是**命题范围**，⛔ 不改字面；
- **§316**：作者**改一个否定字**（「或下利」→「或不下利」）⇒ **改变字面**。

⇒ ⭐ **二者皆需完整语境，但【修改原文字面】的证据要求更高。**
⛔ **不得把 §98 的答案照搬到 §316。**
