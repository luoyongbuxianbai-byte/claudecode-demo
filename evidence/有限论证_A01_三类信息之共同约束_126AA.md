# 一、§59 —— **三类信息齐备之段**

## 1.1 ⭐ 条文与讲解（逐字）

**条文**：「下之后，复发汗，小便不利者，亡津液故也，勿治之，得小便利，必自愈。」

| # | 逐字〔讲伤寒〕 | ⭐ **信息类型** |
|---|---|---|
| ① | 「这个**汗下倒置**，这种治疗啊**没有个不亡津液亡血液的**……所以这个**小便不利是由于亡津液的结果**呀。**这是误治**」〔**77175**〕 | ⭐ **历史信息**（治疗史 ⇒ 来源归属） |
| ② | ⭐⭐ 「就是**阴阳自和**，**表没有什么病，里没有什么病**，只是由于这个大下、复发汗，体液亡失太多了……**没有其他的关系**」〔**77336**〕 | ⭐⭐⭐ **当前观察**（⇒ 「勿治」所依赖之条件） |
| ③ | ⭐⭐ 「他根据这个阴阳自和，**小便不利也是一个不和呀？这个不和没有关系，还算自和之内的**」〔**77433**〕 | ⭐⭐⭐ **「自和」之辖域说明** |
| ④ | 「所以他说是『**勿治**』，**千万不要再利小便了**」〔**77281**〕 | **处置**（⇒ 一个**方向**被排除） |
| ⑤ | ⭐⭐ 「**如果不恢复怎么办？当然也要治，治你不要利小便了。**」〔**77459**〕 | ⭐⭐⭐ **后续分支**（⇒ 变化过程参与决策） |
| ⑥ | 「『得小便利，必自愈』，他由于**津液恢复**，小便自然利的」 | **预期之变化过程** |
| ⑦ | ⭐ 方法纪律：「在临床上**不能（见）一个症状（治一个症状）**」〔77199〕 | 作者自给之方法语 |

## 1.2 ⭐⭐⭐ §59 之**三条限定**（⛔ 126Z 全漏，126AA 补）

| ⛔ 126Z 之写法 | ⭐ 126AA 订正 |
|---|---|
| 「§59 之**来源判据是治疗史**」 | ⛔ **撤（RET-13）**。⭐ ①给来源，⛔ **但②才是「勿治」所依赖之条件**——**表里无他病、无其他关系** |
| 「处置集合**包含【不处置】**」 | ⚠ ⭐ **成立但须带条件**：**不处置**依赖②，且⑤**保留了「不恢复则治」之分支** ⇒ ⛔ **不得抽成无条件不干预**（RET-16） |
| （未写） | ⭐⭐⭐ ③之新得：**「自和」⛔ 不等于「无异常」**——**小便不利本身就是「一个不和」，而作者把它算在「自和之内」** ⇒ ⭐ **「自和」＝异常在可自行恢复之范围内** |

## 1.3 ⛔ §59 **未给**者

- ⛔ 「**阴阳自和**」之**可观察判据**（如何在床边判定「表没有什么病，里没有什么病」）；

# 二、§100 —— **当前观察同时相容于两个候选之段**（⛔ 无治疗史）

## 2.1 ⭐ 条文与讲解（逐字）

**条文**〔**122232**〕：「伤寒，阳脉涩，阴脉弦，法当腹中急痛，**先与**小建中汤，不差者，小柴胡汤**主之**。」

| # | 逐字〔讲伤寒〕 | ⭐ **信息类型** |
|---|---|---|
| ① | ⭐⭐ 「根据这个脉呀，**既有建中证，也有柴胡证**」「这个**柴胡证腹痛也有这种脉**」〔**123110**〕 | ⭐⭐⭐ **当前观察 ⇒ 不足以唯一定证** |
| ② | ⭐⭐ 「**里要是需要温补的，必须先救里**，这个是**先里后外**……**这也是定法**」〔**122789**〕 | ⭐⭐⭐ **次序之依据 ＝【定法】** |
| ③ | ⭐⭐ 「这个**里需温需补都得从里治**，这个**里需攻需下，那就先从外治，这是定法**」〔**123055**〕 | 同上（第二处） |
| ④ | ⭐⭐⭐ 「『**不差者**』，**不差者不是一点没好，总是这个疼没完全好**」〔**122887**〕 | ⭐⭐⭐ **「不差」之读数定义** |
| ⑤ | 「**没完全好，那就是柴胡证的问题了**，所以『小柴胡汤主之』」 | **反馈 ⇒ 处置** |
| ⑥ | 「所以先与小建中汤，这也是**一定的治疗的步骤**」 | 作者称之为**步骤** |
| ⑦ | ⚠ 「要是没完全好，再用小柴胡汤主之，**绝对能好的**」 | ⚠ **作者之强确定性语**（⛔ 无病例） |

## 2.2 ⭐⭐⭐ §100 之三项实得

1. ⭐⭐⭐ **次序不由「哪个诊断更可能」决定，而由【定法】决定。**
　②③两处，作者给的理由是**里之需温补／需攻下**这一**性质分野**，⛔ **不是概率、不是判别力**。
　⇒ ⭐ 与 `T-07` 已立之三路**同型**；⭐ 本批之新处在于：它是在**诊断未定**之情形下仍能给出次序。
2. ⭐⭐⭐ **「不差」＝ 部分改善而残留，⛔ 不是「无效」。**
　④为作者**明给之读数定义**。⇒ ⛔ **「A 不效就换 B」之读法，在本段即不成立**。
3. ⭐⭐ **条文一句之内两级用字**：「先**与**」（丙级·斟酌）／「**主之**」（甲级·固定不移）
　⇒ 见 `U-01`。⭐ **两步不同质**，⛔ 不得当作同一种「试治」。

## 2.3 ⛔ §100 **未给**者

- ⛔⛔ **治疗史**：条文未给；⭐ **讲解全段**〔122232–124000〕**亦未给** ⇒ ⭐ **本段之判断不依赖治疗史**
　⇒ ⭐⭐ **这正是 RET-13 之反证之一**。
- ⛔ 「**腹痛残留**」与「**腹痛未减**」之**区分判据**（④说「没完全好」，⛔ 未给刻度）；
- ⛔ ⑦之「绝对能好」**无任何病例记录** ⇒ ⛔ **属作者陈述**（`M-03` 之第一类材料）。

# 三、§141 —— **唯一明写「追加观察」之段**

## 3.1 ⭐ 条文与讲解（逐字）

**条文**〔**161384**〕：「病在阳，应以汗解之，反以冷水噀之，若灌之，其热被却不得去，弥更益烦，
肉上粟起，意欲饮水，反不渴者，服文蛤散，若不差者，**与**五苓散。」

| # | 逐字〔讲伤寒〕 | ⭐ **信息类型** |
|---|---|---|
| ① | 「**反以冷水噀之**，拿水喷脸为噀……**以凉水浇身**，这是古人用冷水急之，让其出汗的法子」 | ⭐ **历史信息**（⇒ 误治） |
| ② | 「热与水相激，**起鸡皮疙瘩**……这也是**不得汗出的表现**」「热不在胃肠内面，里面无热，所以**反不渴**」 | ⭐ **当前观察** |
| ③ | ⭐⭐ 「**如果服文蛤汤后表解了，但渴不差，还意欲饮水**」〔**161884**〕 | ⭐⭐⭐ **治疗反馈**（⭐ **部分改善**：表解了，渴未差） |
| ④ | ⭐⭐⭐ 「**恐怕这里头有停饮，要详细观察证候，如有小便不利可用五苓散**」〔**161884／161934**〕 | ⭐⭐⭐ **追加观察**（⛔ **新观察项**） |
| ⑤ | ⭐⭐ 「**故用「与」不用「主」**……『与』是**让你斟酌当时的证情**」〔161934〕 | ⭐⭐⭐ **用字之确定性级**（见 `U-01`） |
| ⑥ | ⭐⭐ 「**如果病总是叫渴，又小便不利，肯定里边有停水**」〔**161982**〕 | ⭐⭐⭐ **追加观察后之确证条件**（⭐ 两项**合取**，作者用「**肯定**」） |
| ⑦ | 校改：「**文蛤散是错的**」「所以**应为文蛤汤**」；《金匮》呕吐哕下利篇「**文蛤汤应该是文蛤散**」⇒ **穿插错误**；「『**小陷胸汤**』几个字**应去掉**」 | **校改**（⇒ `C-02`） |

## 3.2 ⭐⭐⭐ §141 之核心：**反馈之后不是答案，是新的鉴别任务**

⭐ **四步逐字可读**：

| 步 | 内容 | ⭐ 所据 |
|---|---|---|
| **1** | 初始信息（②之当前观察 ＋ ①之治疗史）形成候选与处置安排 | ②① |
| **2** | 治疗后**读取残留表现**：**表解了**（已变）／**渴不差**（未变） | ③ |
| **3** | ⭐⭐⭐ **追加观察**：「要详细观察证候，**如有小便不利**」 | ④ |
| **4** | 在**更新后的条件**下选下一处置，且**以丙级用字**给出 | ⑤⑥ |

⭐⭐⭐ **第 3 步之关键**：**所加之观察项（小便不利）⛔ 不在条文原给之观察项内**
（条文所列为：弥更益烦｜肉上粟起｜意欲饮水｜反不渴）。
⇒ ⭐⭐ **治疗反馈引出了一个【新的鉴别任务】，⛔ 它本身不是诊断答案。**
⇒ ⭐ 这与上级 126AA 所定**逐字相符**：「**反馈可以引出新的鉴别任务，不必直接充当诊断答案。**」

## 3.3 ⛔ §141 **未给**者 ＋ ⛔ 两项须并列保留

- ⛔ 「**详细观察证候**」之**清单**——⭐ 作者只举了**小便不利**一项，⛔ 「详细」所指未穷举；
- ⛔ ⑥之「**肯定**」是作者之断言，⛔ **无病例记录**；
- ⛔⛔ **本条有作者提出之校改（⑦）** ⇒ ⭐ **文蛤散／文蛤汤之互换须并列保留**，
　⛔ 不得径以校改后之文字作为底本（`COL` 纪律）；
- ⛔⛔ **「意欲饮水，反不渴」「但渴不差」之措辞须并列保留** ⇒ ⚠ 二者在同条内**方向相反**
　（初诊**不渴**，服后**渴不差**），⭐ 作者未明言其间之转折如何发生 ⇒ **未决**。

## 4.1 ⭐⭐ **信息配置各不相同**

⛔ 故 ⛔ **不得把任何一类立为「唯一判据」**（⇒ RET-13 之根据）。

## 4.2 ⭐⭐⭐ **「不差」之后，作者安排的事三段各异**

| 段 | 「不差／不恢复」之后 | ⭐ 其**性质** |
|---|---|---|
| **§59** | 「当然也要治，**治你不要利小便了**」 | ⭐ **排除一个治法方向**，⛔ **未指定替代** |
| **§100** | 「小柴胡汤**主之**」 | ⭐ **指定方**（⭐ 甲级用字） |
| **§141** | 「**要详细观察证候**，如有小便不利，**与**五苓散」 | ⭐⭐⭐ **要求追加观察**（⭐ 丙级用字） |

⇒ ⭐⭐⭐ **对照所得**：**「治疗反馈」⛔ 不是一件事，⭐ 至少有三种安排**：
**①排除方向｜②指定方｜③要求追加观察。**
⇒ ⛔ **「试治 ⇒ 得诊断」这一读法，三段中只有 §100 近似支持**，
　⭐ 且其支持度**已被用字分级削弱**：「先**与**」本身即丙级（⇒ `U-01` §3.3）。

## 4.3 ⭐⭐ **「不差」＝ 部分改善，两段独立复现**

| 段 | 逐字 |
|---|---|
| **§100** | 「**不差者不是一点没好，总是这个疼没完全好**」 |
| **§141** | 「如果服文蛤汤后**表解了**，**但渴不差**」 |

⇒ ⭐⭐⭐ **两处独立**，⇒ **「不差」之读数是【残留】，⛔ 不是【无效】**。
⇒ ⭐ 这**强化**了 126Z 之 `C-06`，⛔ 但**不改其限度**：⛔ 异写族（不解／不愈／不已）**仍未检索**。

## 4.4 ⭐⭐⭐ **患者状态之变** 与 **我们了解之变**，§141 把二者分开了（⇒ 用户 126AA 之补充）

| | 逐字 | ⇒ |
|---|---|---|
| **患者状态变了** | 「服文蛤汤后**表解了**」 | ⭐ **对象侧之变化** |
| **我们了解不够** | 「**恐怕**这里头有停饮，**要详细观察证候**」 | ⭐ **认识侧之欠缺** |
| **了解推进之后** | 「病总是叫渴，**又**小便不利，**肯定**里边有停水」 | ⭐ **认识侧之推进**（⛔ 对象侧未必再变） |

⇒ ⭐⭐⭐ **这一段是「两者须分别记录」之原文依据**：
**「表解了」是状态变化；「恐怕……要详细观察」是信息不足；「肯定」是信息补足后之判定。**
⛔ 三者在同一句群内**被作者分开说**，⛔ 我方此前一直把它们压成「治疗反馈」一栏。
