> **立册依据**：上级线 126P 令二——「**先做一份小规模对照，不新建庞大分类体系**」。
> 上级并给了骨架五行，本册按其栏目填，⛔ **不扩栏、不建新体系**。
>
> **每条记录七项**（上级明定）：观察如何获得｜原文是否明写｜适用背景｜竞争判断｜

> ①⛔ **不要为了填齐八纲／六经／三毒三类工具，强行让每个观察项同时对应三者。**

## 一、五条对照（⛔ 皆从本段原文提取，⛔ 无一条由模型补表）

### O-01-1　脉浮细

| 栏 | 内容 |
|---|---|
| **观察如何获得** | 切脉 ⇒ ⭐ **医者操作**。⚠ 测量可靠性、时点、指下标准 **原文皆未交代** ⇒ `unknown` |
| **原文是否明写** | ⭐ **条文明写**（「脉浮细而嗜卧者」） |
| **作者用于判断什么** | ①「**细就是津虚血少**」②「**在表的这个津液也虚了，血液也不足了**」③ 与嗜卧合 ⇒「**外已解**」「病**有入内之势**」 |
| **对应何种判断** | ⚠ **津液／血之量**（近八纲之**虚**）＋**病位之动向**（表→半表半里）⇒ ⛔ **本项不对应三毒**，⛔ 不强填 |
| **适用背景** | 「太阳病，十日已去」之后；⛔ **不是**任何脉浮细皆如此 |
| **竞争判断** | ⛔ **脉浮单独 ≠ 表证**——作者本段之「脉但浮者，与麻黄汤」正说明**浮而不细**时仍作表治 ⇒ ⭐ **别在「细」不在「浮」** |
| **支持／排除力度** | ⚠ **须合用**：作者未以脉浮细单独定位；⇒ `requires_conjunction` |
| **治疗差异** | 脉浮**细**＋嗜卧 ⇒ 不可再汗（「看到脉细，你再给吃发汗药就不对了」）｜脉但浮 ⇒ 仍可麻黄汤 ⇒ ⭐ **治法相反** |
| **还缺什么证据** | ⛔ 「细」之操作定义（指下如何算细）｜⛔ 与「脉弱」「脉微」之界｜⛔ 同一医者重复可靠性 |

### O-01-2　嗜卧

| 栏 | 内容 |
|---|---|
| **观察如何获得** | ⭐ **患者报告或旁人观察**（困倦、多卧）⇒ ⛔ **不是**检查所得。⚠ 依上级令二：患者报告**可以是有效证据**，⛔ 但须记其**取得方式** |
| **原文是否明写** | ⭐ **条文明写** |
| **作者用于判断什么** | 「**是这个半表半里，尤其是这个少阳病的一个特殊证候**」「人啊，**病入里了，人就是困倦无力而嗜卧**」 |
| **对应何种判断** | **病位**（半表半里／少阳）⇒ ⛔ 本项作者**未**接八纲寒热虚实，⛔ 不强填 |
| **适用背景** | 与脉浮细并见时；⛔ 单独之嗜卧作者**明否**其充分性 |
| **竞争判断** | ⭐ **作者自设之竞争**：「**光一个嗜卧还是不行的**，如果再胸满胁痛，这柴胡证是具备了」⇒ ⛔ 嗜卧亦可属他因（劳倦、他病）——⚠ 作者**未列**他因 |
| **支持／排除力度** | ⭐ **明非充分**（作者原话）；⇒ `requires_conjunction` |
| **治疗差异** | 若只嗜卧而无胸满胁痛 ⇒ ⛔ **作者未说该用什么**（⚠ 记 `not_recorded`，⛔ 不得推「则不用柴胡」）|
| **还缺什么证据** | ⛔ 嗜卧之程度分级｜⛔ 与「但欲寐」（少阴）之别——⚠ **本批未读到该条**，⛔ 不预判 |

### O-01-3　胸满胁痛（⛔ 上级令五-3 所指之处）

| 栏 | 内容 |
|---|---|
| **观察如何获得** | ⛔⛔ **`unknown`**。「**痛**」几近必为**患者报告**；「**满**」**可能是自觉报告，也可能另有检查表现**——⭐ **原文未交代检查方法** ⇒ ⛔ **不得升级为客观体征** |
| **原文是否明写** | ⭐ **条文明写**（「设胸满胁痛者」） |
| **作者用于判断什么** | 「**胸满胁痛柴胡证啊**」「这柴胡证是**具备**了」⇒ ⭐ **与嗜卧合则定证** |
| **对应何种判断** | **方证**（柴胡证）⇒ ⚠ 并经作者之解释链接到**病位**（结于胁下）；⛔ 不接三毒 |
| **适用背景** | 「设……者」＝**假设追加**；⇒ 在脉浮细＋嗜卧之基础上 |
| **竞争判断** | ⛔ 胸满亦见于 §36（喘而胸满，麻黄汤）⇒ ⭐⭐ **同一「胸满」，§36 归表、§37 归半表半里** ⇒ ⛔ **胸满单独不定位** |
| **支持／排除力度** | ⭐ **与嗜卧合则「具备」**（作者原话）⇒ `decisive_in_conjunction` |
| **治疗差异** | 具备 ⇒ 小柴胡汤；⛔ 不具备则见 O-01-4 |
| **还缺什么证据** | ⛔ 「满」之取得方式｜⛔ §36 胸满与 §37 胸满之别（⚠ §36 有喘、§37 无喘——**这是本批可查之分野线索**，见 §二） |

### O-01-4　脉但浮（⛔ 条文明载与作者补入须分开）

| 栏 | 内容 |
|---|---|
| **观察如何获得** | 切脉；同 O-01-1 之限制 |
| **原文是否明写** | ⭐ **条文明写**（「脉但浮者，与麻黄汤」） |
| **作者用于判断什么** | 「表证应该没有了吧，**他就有吗**，就有你还得解表」 |
| **⛔ 条文明载 vs 作者补入** | ⭐ **条文只给「脉但浮」**；⛔ 作者**另补三项阴性**：「**不细**」「**也没有这一系列的证候**」「**嗜卧呀，胸胁满呀，都没有**」⇒ ⭐⭐ **这三项阴性是作者补入的，条文未写** |
| **适用背景** | 十日已去或更久 |

### O-01-5　十日已去（病程背景）

| 栏 | 内容 |
|---|---|
| **观察如何获得** | 病史陈述 ⇒ **患者报告** |
| **原文是否明写** | ⭐ **条文明写** |
| **作者用于判断什么** | ⭐ **否定其作为固定阈值**：「不一定得十日已去，据我个人这个观察呀，**三四天就有这个事**」「他**怕你固执这个『十日已去』**」 |
| **⛔ 须分辨** | ⭐ **作者否定的是「固定日期决定病位」，⛔ 不是否定时间信息的全部价值**（上级令二明定）——⚠ 证据：他仍说「**十日已去**」是**病程背景**，且「十几天表不解的也有啊」是在**承认时间与常态之关系**之下说的例外 |
| **适用背景** | 全条 |
| **竞争判断** | ⛔ 若以日数定病位 ⇒ 作者明否 |
| **支持／排除力度** | ⚠ **背景项**：不单独支持亦不单独排除 ⇒ `context_only` |
| **治疗差异** | ⭐ **无**——「十几天也好，再日久也好……**该解表还得解表**」⇒ ⭐ **时间不决定治法** |
| **还缺什么证据** | ⛔ 作者是否在他处**用**日数作判据（⚠ 若有，则本条之否定有范围） |

## 四、⭐ 本册新立一问

### Q-024　观察项与八纲／六经／三毒之对应**密度**（⛔ 类＝`survey_task`）

> **范围**：顺序首读**已读区间**（现 `讲伤寒 [0,54482)`）内之全部观察项。
> **完成标准**：逐项记录 ①作者是否把它接到八纲 ②是否接到六经／病位 ③是否接到三毒
> ④是否给失效／漏报条件；并**分别**统计四项之填充率。
> ⛔ **不得**为提高填充率而代作者补接；空着即空着。
> ⛔ 结论之论域须写明为**已读区间**，⛔ 不得写成全书。
>
> ⚠ **本问之用途**：检验一条**方法论预设**——
> 本工程之资产（附录 F/J/K2 等）皆按「观察项 × 八纲 × 六经 × 三毒」建格；
> ⭐ 若原文之对应密度远低于格子密度，则**格中之值有多少来自原文、多少来自补表**，是个可查的量。
> ⛔ **本问不预判该量之大小。**
