## 一、FLIP-03 —— 撤销「火候 ⇒ 病理阶段」之偷换（令四）

### 1.1 上级判得对：我把【火候】当成了【病理阶段】

我 123批 在 `process_stage` 栏写「**燥屎形成阶段**」。
上级指出：现有原文只能证明「转矢气→有燥屎」「大便硬是大承气汤的**火候**」，
**不能**证明「初头硬后溏 → 燥屎逐渐形成 → 已形成」是胡老明确之病理阶段序列。

**而专项检索之后，我须承认上级判得更准，理由在原文里写得很直白**〔A·讲伤寒·262358〕：

> 「大承气汤不要误会它，只要是燥屎就可以用它，是不对的，
> 而是**以燥屎，即大便硬作为用大承气汤的火候或标准**，**不为大便硬而设**。」

⇒ **「火候」＝【用药的标准／时机】，胡老自己就把它和「所治之物」对立着说。**
⇒ 我把一个**决策时机**读成了**病理阶段**。

### 1.2 先按令四重编码

```
pathology_state  : {燥屎存在, 燥屎未证实（初头硬后必溏）}
decision_timing  : {attack_permitted, attack_contraindicated}
process_stage    : unknown_pending_source      ← 先置此
```

**六处「火候」逐处人读之结果**：

| 处 | 内容 | 判 |
|---|---|---|
| 讲伤寒·17172 | **煎药之火候**（「炒个菜，火候要不对头还不好吃」） | ⛔ 无关 |
| 讲伤寒·218086／218162 | 「大便硬是用大承气汤的火候」 | **decision_timing** |
| 讲伤寒·262358 | 「作为用大承气汤的火候**或标准**，**不为大便硬而设**」 | ⭐**decision_timing·决定性** |
| 讲金匮·127330 | 「有燥屎，**到那么个分上了**，用大承气汤，**用它的火候**」 | **decision_timing** |
| 讲金匮·35818 | ⭐「有热说明这个**脓到火候了，脓已成了**」（狐惑·赤小豆当归散） | **⚠ 此处「火候」指【脓之成熟度】，属 process_stage** |

⇒ **「火候」一词在胡老口中至少三义**：煎药之火｜用药之时机标准｜脓之成熟度。
⛔ **不得以「火候」二字之命中数论证任何事**——这正是令七所禁之同类计数。

### 1.4 ⭐ 但另有一处真的找到了【形成顺序】，在 §251 不在 §209

〔A·C卷·65980 §251〕仲景条文：
> 「若不大便六七日，小便少者，虽不受食，但**初头硬，后必溏，未定成硬**，攻之必溏；
> **须小便利，屎定硬，乃可攻之**，宜大承气汤。」

胡老注：
> 「但若小便少者，大便仍初便后溏，**未定成硬**，不可攻之……
> **必须小便利，则屎定成硬，乃可攻之**。」

⇒ 此处确有一个**两档之形成关系**，且**三要素俱全**：
| 要素 | 原文 |
|---|---|
| 两档 | 未定成硬 → 屎定硬 |
| **推进机制** | **小便利**（津液不外走，还入胃中） |
| **等待** | 「**须**小便利…**乃可**攻之」／「必须**待其**小便利」〔解读·179300〕 |

### 1.5 裁决（分两层，不含糊）

| 项 | 判 |
|---|---|
| 我 123批 所写之「**燥屎形成阶段**」（渐变、多档） | ⛔ **撤销**。原文未给 |
| `stool_hardness_settled`：未定成硬 → 屎定硬（**两档**，机制与等待皆由原文给出） | ✅ **成立**，已入 `rules/state_variables_v0.json` |
| 该变量归属 FLIP-03（§209）？ | ⚠ **不完全**——**它出自 §251，不是 §209**。二条同属阳明承气系而条文不同 |
| FLIP-03 之 `process_stage` | ⭐**由 `unknown_pending_source` 改为 `two_state_settled_hardness`，并注明其锚在 §251 而非本条** |

⛔ **说明白一件事**：我**不是**把撤掉的东西又塞回去了。
撤掉的是「**渐变之病理阶段序列**」；恢复的是「**两档＋机制＋等待**」，
**后者的锚是我这批新查到的（§251），123批 报告里一个字也没有。**

### 1.6 并须补 FLIP-03 之两处（来自反例攻击）

## 二、FLIP-08 —— H1／H2 可辨识性审计（令五）

### 2.1 结论先写

### 2.2 ⛔ 理由比「证据不足」更硬：**两类书说法相反**

| 假说 | 逐字 | 书类 |
|---|---|---|
| **H1 真实状态迁移**<br>中虚有寒 → 少阳 | 「不差者，是说服小建中汤后，而病未全解除，**这时病多转属少阳小柴胡汤证**，故**不应再用小建中汤**」<br>「假如症状没全消除，**知已转属少阳**，当用小柴胡汤治疗」 | **注解本**<br>〔A·解读·100487〕<br>〔A·传真系·30331〕 |
| **H2 竞争状态本已共存** | 「**根本这个脉呀既有建中证，也有柴胡证**，在这个治疗的结果上来看」<br>「那么**既可能是**建中证，**也可能是**柴胡证」 | **讲课本**<br>〔A·讲伤寒·123110〕 |

⇒ **不是我读不出来，是两本写的不一样。**
⇒ 与 CE-02（条文只四症／讲义给分野项）同型——**`source_version` 落差之第二例。**

### 2.3 上级四问之逐条答

| # | 问 | 答 |
|---|---|---|
| 1 | 「转属少阳」是病理传变，还是诊断重分类？ | ⛔ **两本不同，本批不判** |
| 2 | 有无**治疗前**已同时具柴胡证之说明？ | ⭐ **有**：「**根本这个脉呀既有建中证，也有柴胡证**」——「根本」即本来、原就 ⇒ **治疗前已共存** |
| 3 | 有无「不差」后仍**无**柴胡方证之案？ | **未查得案**。⚠ 但胡老**为这种情形留了口**：「『不差者，小柴胡汤主之』，是**必看有小柴胡汤方证时**，方可用小柴胡汤」〔解读·100651〕。**若『不差』必然转柴胡，此诫即成废话。** |
| 4 | 有无完整反馈链之医案？ | **未查得**。`小建中…小柴胡` 30 处皆条文与注解；`case_layer/` 19 件无此链 ⇒ `not_found_within_audited_scope` |

### 2.4 ⭐ 第 2、3 问之答倾向 H2，而我仍不择一

- 第 2 问给出**治疗前共存**之逐字 ⇒ 支持 H2
- 第 3 问之胡老诫语，**只有在「不差 ≠ 必转柴胡」时才有意义** ⇒ 支持 H2
- **但 H1 在注解本有两处逐字**（「病多转属少阳」「知已转属少阳」）

⇒ **两侧都有逐字，故判 `disputed`。**
⛔ 我**不**因为 H2 证据看起来更顺就择一——**那正是本工程反复出事的地方**。

### 2.5 Decision 链（令六·并保持不直通）

```
服小建中后「不差」
   → 柴胡证候选升高          （⛔ 不是「已转属少阳」）
   → 重新验证小柴胡【方证】    （胡老：必看有小柴胡汤方证时）
   → 方证成立 → switch
   → 方证不成立 → ⛔ 本工程无出口（原文未给），记 unknown
```

⚠ 最后一行是我加的**缺口标注**，不是原文所有：
**胡老只说「必看有方证」，没说「没有方证时怎么办」。**
