## 二、⭐⭐ 作者层：他据以选择的表现（⛔ 逐条标层）

### 2.1 T0 —— 为何「此误也」

| 层 | 内容 |
|---|---|
| 【条文】 | 只写「反与桂枝汤，欲攻其表，此误也」，⛔ **未给理由** |
| 【作者】 | 「**小便数**说明什么问题呢？**大概是胃虚**」⚠ 低确定性标记 |
| 【作者】 | 「这个恶寒**很轻很轻**的了，这个**表要罢**」 |
| 【作者】 | 「**这个心烦**，这个**里热要升**……就是因为**津液丧失**」 |
| 【作者】 | ⚠**缺省推阴性**：「你看看这里头**一点热都没提**，他也**不发热**不什么的，你吃哪路桂枝汤啊」 |
| 【作者】 | 「**凡是应该发汗的病，小便数绝不可以发汗**」＋引《金匮》 |
| ⇒ | 作者据以否定桂枝汤者**至少四项**：小便数｜恶寒之轻重｜心烦（里热）｜⚠ 未写发热 |

⭐ **[我方]** 值得注意：⛔ **这不是「津液虚 ⇒ 禁汗」一条链**。
「恶寒很轻 ⇒ 表要罢」与「心烦 ⇒ 里热要升」是**两个方向相反的判断**（表退、里进），
作者把二者**并置**作为「不可再攻表」之理由。⇒ ⭐ **决策依据是一个状态的多项组合，不是单一量。**

### 2.2 T1 —— 为何甘草干姜汤（⛔ 而非附子剂）

| 层 | 内容 |
|---|---|
| 【条文】 | 「得之便厥，咽中干，烦躁吐逆者，作甘草干姜汤与之，**以复其阳**」 |
| 【作者·释义】 | 「『以复其阳』啊是**复津液**……这个『阳』和我们头前说的**津液是一致的**」⇒ ⛔ 否定「复热」读法 |
| 【作者·选药】 | 「甘草……**能够养液，也能缓急迫**」「干姜甘草搁到一起，就是**健胃，治呕**」 |
| ⭐【作者·边界】 | 「**四肢厥逆，没陷入阴证**；陷入阴证**非用附子不可**，**没到那个程度**，所以用甘草干姜汤就可以了」 |
| ⭐【作者·反面】 | 「这个病我想要用专讲**滋阴救逆**的这种办法**一吃一个死**……他这个胃根本是不好的，**也只能够恢复胃气才能够生津**」 |

⇒ ⭐⭐ **本处是本段最完整的一次「为何是此方而非彼方」**：
作者同时排除了**两个方向**——①附子剂（**未到阴证**）②滋阴剂（**胃坏则不能生津**）。
⇒ ⭐ **[我方]** 判别项是「**是否已陷阴证**」与「**胃之状态**」，⛔ 不是「津液虚之程度」。

⚠ 并须记：「一吃一个死」是 ⚠**经验性反驳陈述**，⛔ **无病例记录**。

### 2.3 T2 —— 为何换芍药甘草汤

| 层 | 内容 |
|---|---|
| 【条文】 | 「**若厥愈、足温者**，更作芍药甘草汤与之，其脚即伸」 |
| ⇒ ⭐ | **转移条件是「已变之表现」**（厥愈、足温），⛔ 不是「仍在之表现」 |
| 【作者】 | 「他津液**一达到四肢**他自然就不厥了……**这个时候啊，脚挛急没好啊**」 |
| 【作者·选药】 | 「芍药……它是个**治挛急**的……**其他的部位发拘挛呢？芍药也治**」 |
| ⭐【作者·异议】 | 「**我说开始就应该吃这个药**」「**当然是以吃芍药甘草汤为最好了**」 |

⇒ ⭐⭐ **T2 之结构最完整**：**一项已变（厥愈、足温）＋ 一项仍在（脚挛急）⇒ 换方**。
⭐ **[我方]** 这是本段唯一一处**同时出示「已变」与「仍在」两类信息**的时点。

⛔ 并须分层：作者**不同意条文之起手**（主张径用芍药甘草汤）
⇒ ⛔ **不得把作者之主张写成条文之义**。

### 2.4 T3 —— 为何「少与」而非攻下

见 §1.2。并记【作者】之附加限定：
「他这个里边的胃不和**不是个重要的**……**这个不是阳明实结的那个厉害**」。

### 2.5 T4 —— 假设支

| 层 | 内容 |
|---|---|
| 【条文】 | 「若重发汗，复加烧针者，四逆汤主之」 |
| ⭐【作者】 | 「他是**假设**说的……**没有这么糊涂的大夫**」 |
| 【作者】 | 「那**非陷于阴证不可**……那你**非用四逆汤才能治疗**呢」 |
| ⇒ ⭐ | **[我方]** 作者明标此支为**假设**，⛔ 不是已观察之转归 ⇒ 记 `hypothetical_branch` |

⭐ 与 T1 对读：T1「**没到那个程度**」／T4「**非陷于阴证不可**」
⇒ ⭐ **同一条轴（是否陷阴证）之两端，作者用它区分甘草干姜汤与四逆汤。**

## 三、⭐ §30 之复核：同一过程之第二次叙述

⚠ §30 对同一过程另作一遍，且**有三处与 §29 不同**：

| 项 | §29 | §30 |
|---|---|---|
| 谵语之位置 | **末段**（甘草干姜、芍药甘草之后） | ⭐ **前移**至误治直后（「厥逆，咽中干，两胫拘急**而谵语**」） |
| 误治之方 | **桂枝汤** | ⭐ **桂枝加附子汤＋增桂**（「因加附子参其间，增桂令汗出」） |
| 四逆汤支 | 有（假设） | ⭐ **无**——作者：「后边呢就**把这个四逆汤抹去了**」 |

⇒ ⭐【作者】明说 §30「**比上一段说明得好**」。
⚠ **[我方]** 但三处不同**未被作者一一交代**：
他只解释了谵语之位置（「**可见，开始就是经过服过桂枝汤之后，这个谵语就发生了**」），
⛔ **未交代**为何误治之方由桂枝汤变为桂枝加附子汤、为何四逆汤支消失。
⇒ ⚠ 记 `unexplained_divergence`，**两项**。

⭐⭐ **并一条重要之治疗选择**：§30 之误治是**桂枝加附子汤**，
而【作者】评曰「**他这都是错的**」「附子温经……那更令汗出了，那更使之亡阳」
⇒ ⭐ **作者在此否定了一个「看似更稳妥」的方**——
与 §三所查之〔伤寒论传真〕「**桂枝加附子汤亦不行，尤其后者，更易误施**」**同一主张**。
⚠ ⛔ 二者之独立性未定（同 126L §3.3 之三道限制），⛔ **不增独立证据数**。
