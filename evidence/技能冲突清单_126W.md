# 四、⭐⭐⭐ 工具不能检查的语义问题，由谁继续检查（上级令二之边界三）

| 问题 | ⭐ **现有检查器之覆盖** | ⭐ **由谁裁决** |
|---|---|---|
| 锚之文件是否存在｜定位符是否在标题行｜编号是否唯一｜status 是否合法 | ⭐ **可** | `tools/report_index.py --check` |
| 清洗降幅｜基线偏离｜资产清单减少 | ⭐ **可** | `corpus_guard --audit`／`manifest --check` |
| 账本区间是否连续自洽 | ⭐ **可** | `reading_ledger --verify` |
| 未验证归因之引用处有无标记 | ⭐ **可**（字面） | `tests/test_text_critical_gate.py` G5 |
| ⛔ **某句是否仍被当作【现行结论】** | ⚠ **现有检查器未覆盖** ——⭐ 但**可辅助**：`grep` 原句与近义串、`report_index` 三栏遍历，**能缩小范围** | ⭐ **人读裁决**：执行位置一之第②步 |
| ⛔ **蕴涵方向是否用对** | ⚠ **现有检查器未覆盖**；⭐ 可辅助：扫「不得／排除／不成立／从未／全部」等**模态词**并逐处提请复核 | ⭐ **人读裁决**：执行位置二之前置表 |
| ⛔ **作用域是否被悄悄放大** | ⚠ **现有检查器未覆盖**；⭐ 可辅助：比对同一命题**前后批之 scope 栏**是否变宽 | ⭐ **人读裁决**：⚠ 已发生**五次**（有热→阳明｜无汗→状态相当｜三形态→任何线索｜一方→一切含麻黄方案｜⭐ **126W 之「里之外」→「表」**） |
| ⛔ **证据是否足以支持该命题** | ⚠ **现有检查器不能可靠裁决** | ⭐ **人读 ＋ 上级复核** |

⇒ ⭐⭐ **一条纪律**：**「工具全绿」只覆盖上表前四行。**
