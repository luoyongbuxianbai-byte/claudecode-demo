# 取证协议 · source_layer **七步检索顺序**（retrieval stages）
（123批立｜124批依上级令八更名）

> ⛔⛔ **124批 更名之要点：「七级」改称「七步检索顺序 / retrieval stages」。**
> **它只是检索路径，不代表证据等级。**
> 医案虽排在第 5 步，**不意味着证据弱于第 4 步**。
> 每个命中仍须**独立**填写 `source_layer`／`speaker_status`／`text_status`／`source_version`／`scope`，
> ⛔ **不得以「它在第几步被找到」推断其证据强弱。**

## 〇、本协议因何而立

**CE-02 胸痹**已证：

```
L1 仲景条文之观察集   ⊊   L2 胡老临床实际所用之观察集
```

《金匮》条文只记「心中痞、气结在胸、胸满、胁下逆抢心」四项，
而胡老在讲义里补进了**呕逆、心下痞坚**（人参汤侧）与**无胃上之一切毛病**（枳实薤白桂枝汤侧），
并明言「**不是说这两个方剂治同一个证，张仲景没有这个情形**」〔A·讲金匮·113609〕。

⛔ **我 121批 只读了 C卷 一窗，就写成「胡老未给可观察分野项」——错。**
⛔ **122批 我又在 FLIP-02 肺痈上犯同一错**（判「脓已成无入口」，
　 而入口在同书〔讲金匮·85483〕「**时时振寒**……**吐如米粥**」）。

**两次都是：一个窗口里没看见，就写成「原文没给」。**

---

## 一、适用范围（何时必须走本协议）

凡作下列任一裁决者，**必须**先走完第二节之七步：

- 「不可辨识」
- 「无观察入口」
- 「同症异方」
- 「原文未给分野项」
- 「本条缺 X」

---

## 二、七步检索顺序（须依序，且逐步留痕）

| 步 | 查什么 | source_layer |
|---:|---|---|
| 1 | **仲景条文本身** | `L1_fact` |
| 2 | **胡老对该条之注解** | `L2_hu_behavior` |
| 3 | **胡老讲课全文之对应段** | `L2_hu_behavior` |
| 4 | **胡老同方之方解** | `L2_hu_behavior` |
| 5 | **胡老同方之医案** | `L3_response` |
| 6 | **胡老跨书同主题论述** | `L2_hu_behavior` / `L4_hu_theory` |
| 7 | **若各层冲突** | ⛔ 记 `versioned` / `disputed`，**不得静默合并** |

⚠ 第 3 步与第 2 步之别要紧：**同一条，注解本与讲课本常不同**。
　 CE-02 即是：C卷（注解本）只说「虚实不同耳」，讲金匮（讲课本）给全了分野项。

---

## 三、结论用语之三档（⛔ 不得越档）

| 走到哪 | 只能写 |
|---|---|
| 七步未走完 | **「本窗口未见」** |
| 七步走完仍无 | **「入口在已审范围内未查得」**，并**附检索式与检索范围** |
| 任何情况 | ⛔⛔ **不得写「不存在入口」／「原文没给」／「全库无此」** |

〔与闸门9⑦同源：**不得以检索宣称「全库无此规则」**。本协议是其在【入口缺失】判定上的对应款。〕

---

## 四、留痕格式（机器可查）

每条此类裁决须附：

```
source_layer_search:
  stages_done: [1,2,3,4,5,6]        # 实际走到第几步 ⛔【步】不是【级】，与证据强弱无关
  queries: ["脓已成", "振寒", "吐如米粥"]   # ⛔ 逐条记检索式
  books:   ["讲金匮", "C卷"]           # ⛔ 记检索了哪几本
  verdict: "entry_found" | "not_found_within_audited_scope" | "window_only"
  conflict: none | versioned | disputed
```

⛔ `verdict` **无 `no_entry_exists` 这一取值**——该判断本工程不产出。

---

## 五、本协议自身之限度（须写明，不得含糊）

1. **七步走完仍是「已审范围」，不是「全部」。** 语料只有十二书，
   胡老之言不止于此（讲课录音、未刊讲稿、他人转述皆不在库）。
2. **第 5 步（医案）现有 `case_layer/` 19 件，远不覆盖全部方证。**
   ⇒ 故「医案层未见」之**信息量**弱于「注解层未见」——
   ⛔ **但这是【覆盖率】之差，不是【证据等级】之差。**
   若医案齐备，医案之证据力并不低于注解；今之弱，弱在我方语料只有 19 件。
3. **本协议只管【入口有无】，不管【入口可靠】。** 找到入口之后，
   仍须过 `speaker_status`（谁在说）与 `text_status`（各本是否一致）两关。

## 六、124批 补·每个命中须独立填之五栏（令八）

| 栏 | 说明 |
|---|---|
| `source_layer` | L1_fact／L2_hu_behavior／L3_response／L4_hu_theory／L5_editorial／L6_engine |
| `speaker_status` | zhongjing／hu_verbatim／hu_paraphrase／**editor**／uncertain |
| `text_status` | consistent／disputed／emended_by_hu／variant |
| `source_version` | 哪一本、哪一版（**注解本与讲课本须分**） |
| `scope` | 该命中所处之域 |

⛔ **五栏俱全方算一条证据。** 只记「在第 N 步查到」者，不算。

### ⭐ 本协议已两次触发第 7 步（各层冲突 ⇒ disputed，不得静默合并）

| 例 | 冲突形态 |
|---|---|
| **CE-02 胸痹**（122批） | **条文**只四症 vs **讲义**给出呕逆／心下痞坚 ⇒ 观察集落差 |
| **FLIP-08 §100**（124批） | **注解本**作「多转属少阳」（迁移） vs **讲课本**作「既有建中证，也有柴胡证」（共存） ⇒ `disputed` |

⇒ **两例皆为【注解本 vs 讲课本】之落差。** ⛔ 此形态须列为常查项，凡只读一类书即下裁决者，视同未走完七步。
