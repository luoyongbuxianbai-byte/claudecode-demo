2. 三系统与十四项的结构审查

血液循环系统、筋膜—间液系统、细胞机能不是三个同尺度、互不包含的单位。血管、腺体及筋膜组织同样涉及细胞功能；“间液”是介质，“筋膜”是组织结构，“能量代谢”是过程。可作为观察视角，不宜直接计算成三套独立病理之和。

3. 对当前现代解释的有限核验

• 自汗不能写成血溢脉外。 汗液由汗腺分泌并经导管到皮肤表面；血管外渗与出汗不是同一个生理事件。一般生理依据：OpenStax皮肤附属结构。此依据不证明任何方的疗效。
• 水吸收不能靠“提高细胞渗透压”一句解释完。 必须说明跨上皮运输、溶质梯度和净水流；胃肠腔内液体亦不能直接叫废水。一般生理参照：OpenStax消化与吸收。本次未证明白术在相关患者、剂量与配伍下通过所述路径止泻。
• “麻黄打开全身腺体”“杏仁疏通肺筋膜间液”“柴胡归还中下焦血液”“炙甘草稳定全身细胞膜”等均未获本次验证。须列研究对象、剂型、暴露、作用环节与终点；单味成分、动物实验、全方人体结果不可互相替代。

6. 三毒不能被三系统取代

水毒不自动等于一切组织液，血相关问题不自动等于一切循环异常，宿食不自动等于全部胃肠动力障碍。阴阳也不自动等于所有细胞的亢进/衰弱，寒热不直接等于局部温度，虚实不直接等于物质量多少。

建立对应时须回答：古典词在该段指什么；有哪些可观察依据；它与所拟现代变量是同义、部分重叠、相关、因果还是未知；若不同会导致哪种错误处置。正常物质/功能与病理状态的界线不能省略。
