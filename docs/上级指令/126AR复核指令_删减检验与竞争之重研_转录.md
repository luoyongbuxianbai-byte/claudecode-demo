我已拉取 126AR cc2ad46，读了 U-01、U-02，并对照 §67、§40、§277 原文。

六项旧错误确实得到处理，但两个新样本还不能验收。 问题尤其集中在 U-02：它刚承认不能把缺省当阴性，又把“没写发热”写成“无发热”；刚开始研究联合判断，又未经检验宣布“四项缺一不可”。

这次需要把错误发生的具体步骤拆开，不能再靠下一轮换几个形容词解决。

一、§67 本身已经提供反证，不必先到别处找。

U-02 写：

少任何一项，处置都定不下来。
少治疗史，不知胃虚从何来；少眩，不知水在胃。

但同一个完整单元后面，胡老明确说：

“不是发汗后，不是吐下后，我们在临床上一般的头晕多属这个方子……”

这至少说明：吐下史不是该方所有应用场景的必要条件。 不知道状态怎样发生，也不等于不能通过当前表现识别状态。

此外，本条已有“心下逆满”，作者明确解释“心下，就胃这个地方”。因此，“少眩便不知水在胃”也没有成立依据：Code 把一个观察承担的作用，误写成只有这个观察才能承担。

真正需要研究的是：

* 哪些信息彼此补充？
* 哪些能够部分替代？
* 哪些改变判断？
* 哪些只解释来历？
* 哪些在特定范围内确实不可缺？

“每项有作用”不等于“每项都是必要条件”。 这正是此次应当教会 Code 的方法。

二、§67 与 §40 的对照，仍含未经证明的分野。

U-02 对照表写：

新判断	问题
§67 表证弱，只剩气上冲，无发热	没记发热不能写“无”；也没有独立证据判表证强弱
§40 表证强，因为有发热	有发热不自动证明比 §67 表证更强
§67 水在胃，§40 水射于肺	§40 同样明写“心下有水气”；水的所在、症状表现与作用方向不能互相替代
§67 只利水	作者同时明确说桂枝甘草降冲气，不能删去这个治疗目标
是否需要解表取决于表证还剩多少	目前是我方待证解释，不能写成已取得的分辨规律

§40 的核查有价值：它使“有饮一律禁汗”不能保留。

但是，推翻旧解释，并不自动证明新解释。 目前可以保留的是：

§67 作者选择利水、治气冲，并反对在该情境下发汗；§40 作者选择去饮与解表并用。两者如何分辨，尚须研究，不能用未经记录的“表证强弱”补齐。

还有一个更直接的问题：U-02 说“本条没有竞争判断”。可原文正在问：

“表没解得解表……可是这个情形啊不能吃发汗药，非利水不可。”

这里有处置竞争：继续发汗，还是改用利水治冲。末尾又以“胃发炎而没有水”讨论白术不适用，并以恶心引出另一方证方向。

所以不是“没有竞争”，而是 Code 把竞争理解得过窄，只找并列诊断名称，没有看作者怎样排除行动和用药。

三、U-01 把解释关系写成了过长的固定算法。

它写：

小便白→寒→虚归阴→阴证→太阴／少阴→温法→四逆辈。

这里至少要拆开三个问题：

1. 寒热虚实与阴阳的分类关系，不等于必须按这个顺序执行。
    太阳篇总结既讲总体阴阳，又讲类内细辨。“先辨阴阳”和分类关系并不因此构成次序冲突，不能先制造一个冲突再列为缺口。
2. 里热不能直接推出承气下法。
    U-01 写“若里热→阳明→下法”，漏掉是否里实、是否需要攻下等条件。它正重演“六经标签代替方证分析”。
3. 没有尿色，不等于整个判断不能成立。
    作者明说“或者以脉，或者以尿”。尿色这一通道缺失，应检查其他证据能否分辨，而不是宣布无法判断。更不能把“你要好好看”转述为作者已经规定“无尿色则不判”。

另外，“里热”和“津液不足”也不能未经限定称为互斥状态；需要区分的是本次口渴的解释及治疗约束，而不是排除二者并存的可能。

⸻

给 Code 的下一批指令如下。

先修两个样本，不新增 skill、分类或模板。

1. U-02 撤回四项未经证明的判断：
“四项缺一不可”；“无发热、表证弱”；“水在胃与射肺构成已证分野”；“只利水”。用 §67 本段后半的临床扩展、心下释义和降冲气用法，逐项说明为什么撤。

2. 重新研究 §67 的竞争。
分开记录诊断竞争、治法竞争、药物适用竞争。至少实际处理“为何不继续发汗”“为何不能见胃病便用白术”两项。不能因作者没列两个诊断名，就说没有竞争。

3. U-01 撤下“里热即下法”“无尿色则整个判断不成立”“阴阳判断不会翻车”。
将作者明确判断、跨段引用、我方推导逐步分开。分类关系不得冒充执行顺序；推导每一步都要检查是否缺前提。

4. 做一次信息删减检验，使用原文已经提供的变化，不编病例。
以 §67 为例：没有吐下史，作者是否仍使用本方？没有眩的资料时，心下逆满能支持到哪一步？没有尿色时，§282 是否提供其他观察通道？
结果分别记为“仍有支持”“支持减弱”“当前无法分辨”，不要统一判失效。

5. 区分原文未命名与我们不能推导。
§67 的里、寒、虚、饮可与作者总论建立明确标注的重构关系。不能因为本条没写“太阴”就停止研究；也不能据此直接给整个患者或整张方贴太阴标签。须区分里部状态与同时存在的表证。

6. 验收先看推理，再看传播。
修正须同步到 M-01、两个样本及报告的现行结论。历史原文保留，不让旧结论继续作为当前判断。完成上述核证后恢复顺序阅读，避免整批只做文字修补。

我这边也要修正一句：上一轮称 §67 为“独立迁移”，不够准确。 样本由我指定，且此前已有讨论；它可以检验方法迁移，不能算盲测。Code 本批称两个样本都是自己选的，同样与实际经过不符。

目前可观察到的主要问题是：为了交付一条完整链，Code 把有贡献的观察升级为必需，把没有记录升级为不存在，把可能的分野升级为已证分野。 这也是我不能仅靠提供“完整链模板”来解决的原因：模板若要求每格填满，反而会诱发补造。

结论：126AR 有实际核查进展，但方法尚未稳定。下一步应检验“每个连接凭什么成立、是否存在替代证据”，而不是继续追求链条看起来完整。
[置信度：高；上述问题可以直接由本批文件与 §67、§282 原文对照确认。]

该结论成立的充分必要条件：本次材料足以判定这些具体推论尚未成立；不足以证明 Code 永远无法稳定改进。改进是否有效，仍须看后续材料中能否在交付前主动发现同类错误，不能由修正数量代替。
