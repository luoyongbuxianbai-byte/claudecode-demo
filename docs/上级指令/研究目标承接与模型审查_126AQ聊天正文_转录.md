需要继续把后续方剂按同样格式提取吗？你的批评有依据：我们已有不少局部原文，却还没有把“脉与症候—当前状态—八纲六经三毒—治法方药”组织成系统、可审查的对应论证。 我之前过多交付了读记、边界提醒和错误订正，没有充分交付你真正要研究的关系。

但这次必须同时完成两件事：准确承接你的研究目标；审查你提出的三系统、十四单元是否足以承担这些解释。不能因为它表达得系统，就把其中尚未证明的现代机制当成事实。

1．你这次提出的核心，是“状态组合与干预组合的对应”，不只是给方剂换一套术语。

可以整理成以下研究命题：

患者的表现来自若干相互作用的状态变化。八纲、六经、三毒应当帮助辨认这些变化及其关系；脉、症候和治疗反应提供辨识依据。方剂中的药物及配伍，则针对其中不同环节，同时受患者耐受、病程、部位和禁忌约束。

因此，研究应回答：

* 为什么同有“水”的问题，用药不同？
* 为什么同样呕吐，有时需要温、有时需要其他处置？
* 为什么同一味药在不同配伍中作用不同？
* 为什么脉的某种变化，在此背景下支持这个判断，换背景便不能照用？
* 为什么某个状态必须先处理，另一个可以暂缓？

这些问题最后必须回接八纲、六经、三毒，不能被“微循环”“细胞机能”等新名词绕过去。 暂时不能回接的，要明确说明缺哪一步证据。

2．三系统可以作为研究视角，但目前不是三个同层级、独立的系统。

这里恰好有一个你一直要求我们防止的层级问题：

你的分类	当前混合的对象
血液循环系统	器官与组织层面的运输系统
筋膜—间液系统	组织结构＋液体介质＋交换过程
细胞机能系统	前两者内部也存在的功能层级

血管、腺体和筋膜组织都涉及细胞功能。所以不能把“循环异常＋间液异常＋细胞异常”直接当作三个独立病因相加，否则可能把同一过程的不同环节重复计数。

十四项内部也有类似问题：末梢供血障碍可能包含血供不足，血管痉挛可能是其原因；筋膜粘连与痉挛不是同一概念；“黏膜应激紊乱”目前还缺可辨识定义。

这不要求再增加几十个单元。应先把现有项的对象、部位、过程、指标和包含关系说清楚。

3．几处现代生理解释必须改，不能仅标“有待完善”。

最明确的是：

* “防止血溢脉外（自汗）”不成立。 出汗是汗腺分泌经导管到达皮肤表面的过程，不能等同于血液外渗。皮肤与汗腺结构⁠￼
* “白术提高细胞渗透压，把废水回收”尚未得到这里所需的证据。 肠腔水吸收必须明确跨上皮运输、溶质梯度和净水流；“胃肠细胞渗透压”一句不足以确定路径，更不能证明白术通过这条路径止泻。消化与吸收机制⁠￼
* “少阳＝全身筋膜痉挛”“柴胡归还中下焦血液”“麻黄打开全身腺体”“甘草稳定细胞膜”，目前在你提供的材料及本次核验中，没有获得足以支持这些具体连接的证据。不能作为现行结论。

尤其不能从“胸胁苦满”直接推出筋膜粘连，再由“小柴胡汤治胸胁苦满”反证它能松解粘连。这会形成循环。

4．我这次实际重读后，可以先交付一条完整的脉—状态—方药对应链。

《讲伤寒》§12完整单元 [12835,18548)，作者不是只说一个“浮弱脉”。

1. 取法与观察：“轻按浮”，再按则“不禁按，弱”。这里的“阳浮阴弱”，作者解释为脉的外内，不能直接判患者全局同时阴阳。
2. 与症候合看：作者将汗出与脉弱联系起来，结合汗出而仍有病的表现。
3. 状态解释：作者判断津液已有损伤，精气不足以驱邪。这是作者的解释，尚不是现代区室液体测量。
4. 干预约束：因此不宜再大发汗，作者据此说明为什么不用麻黄式强发汗。
5. 配伍作用：桂枝、生姜承担其所说的发汗等作用；芍药兼有制约辛散与养液；甘草、大枣等又联系胃气。并非每味药只对应一个系统。
6. 反馈与停止条件：方后还包括温覆、稀粥、微汗目标、病差停服和未汗时调整，不能把全部作用只归给药味。

这条链回到你的核心：

要回答的层面	本段目前能支持什么
六经	在太阳中风语境内研究，不由脉浮弱单项定经
八纲	涉及表证及虚的解释，须保留具体对象
津液	作者明确讨论损伤
三毒	本段尚未独立建立水毒、瘀血或宿食为核心；不能把津液损伤直接写成水毒
方药	状态限制发汗强度，并影响配伍和服法
现代机制	末梢低灌注、间液亏虚、渗透压失衡仍需另证

这才是我们应该不断累积的研究产物。 不是列出“桂枝汤＝某几个病理单元”就结束。

麻黄汤还有一个需要正面研究的差异：§35作者用“体表水分多”“血管里充分液体”等解释；你提出的是“血流难以抵达末梢”。两者不能未经测量就当作同一个机制的两种说法。

6．三毒和脉象的对应，今后必须成为交付内容，不能继续只是待办名称。

需要守住几个区分：

* 水毒不自动等于一切组织液；
* 血相关问题不自动等于全部循环异常；
* 宿食不自动等于全部胃肠运动异常；
* 太过／不及须说明是哪一维、相对什么参照；
* 脉的触觉描述、作者状态判断、现代测量指标是三种不同证据。

对应关系可以是有条件、部分重叠、多对多的；不必为了整齐变成一对一。 但这不是逃避建立对应，而是要求每一条对应说清：什么条件下成立、能改变什么判断、什么情况不能用。
