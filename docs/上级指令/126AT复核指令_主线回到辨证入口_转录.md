你指出的是研究依赖顺序错了：当前状态尚未辨清，我们却把主要精力放到治疗次序、方药解释和反馈上。我上一轮直接指定研究治疗次序，确实把主线带偏了。

首要任务是：依据当时实际可获得的信息，说明患者当前是什么状态，为什么这样判断，还有哪些状态不能排除。 八纲、六经、三毒，以及你列举的脉、舌、腹、汗、二便、饮食、津液、胃气、病程、既往治疗等，都必须真正进入这次判断，而不是在结论后补几个标签。

这里有两个必须同时避免的错误：

* 不能只辨出“太阳”“水饮”，便认为已经辨清患者。
* 也不能要求把所有可能机制全部证明，才能形成有限的辨证判断。

你要的是辨到足以支持下一步决策的状态精度；材料不足时，明确卡在哪里、补什么观察能继续。

我把首要研究任务具体改成下面这条链，暂不进入选方：

1. 保留观察本身。
    不只记“眩、渴、吐、脉沉”，还要保留发生条件、程度、部位、同时或先后关系、取脉方式。主观感受也是观察资料，但与测量值、作者解释分别记录。
2. 明确每项观察正在回答什么。
    它支持病位、阴阳、寒热、虚实、病理因素，还是病程变化？同一观察可以参与多个判断，但每个连接都要说明依据，不能预先固定一项只管一层。
3. 形成有作用域的当前状态判断。
    哪里出现什么病情？哪些是并存，哪些是先后变化？津液不足与停饮能否同时存在？所见症候是本位表现还是受累表现？能辨到哪一级就写到哪一级，不把未辨清的机制补出来。
4. 比较竞争状态。
    相同表现还有什么解释？现有脉证支持哪一个、削弱哪一个？哪个关键观察尚未采集？未被排除不能算成立，缺项也不能用于排除。
5. 回接八纲、六经、三毒并检查一致性。
    这些工具是否共同描述了同一个当前状态？有没有把局部寒热升级为全身属性，把“人虚”和“病实”互相排斥，或把方名偷带进判断？若某一层暂时不能归类，保留已辨清的部分，不让整次判断归零。

这五步的产物才是辨证研究的入口成果。 治则、治法、方药与反馈随后检验和使用这个成果；不能反过来依靠已知处方，把入口补得看似正确。

因此，126AT 的病例目前不能算完成了这个任务。按你贴出的报告，它采用“作者初诊判语与讲义规定相同”，核对了作者判断和处置是否一致；尚未展示：遮住作者判语和处方后，仅凭初诊事实，怎样得到这个状态判断。 “脉变而主方不换”也不能直接解释成“脉只是疗效读数”，还须看其他状态信息是否改变。

给 Code 的指令应立即改为：

下一批主件改为“辨证入口示范”，不继续把治疗次序作为主件。

使用已经取得的王某案，先核完整初诊原文。将作者诊断、方名、药物和后续疗效与初诊事实分开保存。

先只展示初诊事实，完成上述五步。 必须具体回答：

* 病位依据是什么？哪些部位尚不能判？
* 阴阳、寒热、虚实分别凭什么判，是否混用了同一个词的不同含义？
* 水饮等病理因素凭什么成立，与津液不足等竞争状态怎样区分？
* 脉沉、细、滑、数如何在这一整组症候中解释？哪些仍不能解释？
* 哪些观察真正改变判断，哪些仅提供支持？
* 还有什么必须补采，才能达到足以讨论治法的精度？

然后再揭示作者判断，逐项比较一致、分歧和无法重建处。不能因作者用了某方，就回填所需症候或病机。

这个病例已被我们看过答案，因此这是受污染材料上的推理重建，不是盲测，也不报告准确率。若简案不足以重建，就交付具体缺口，不能强做成功示范。

连续阅读继续，但深入研究优先服务这个入口：先解决“怎么辨当前状态”，再研究“因此怎么治”。

我也补充一个关键点：不是把八纲六经三毒依次填满，就叫辨证完成。 必须能说清各层之间的对应依据，并解释为什么同样的脉、同样的渴或同样的小便表现，换了背景就可能改变判断。这才是在落实你的猜想，而不是形式上照用了术语。

结论：现在主线应回到“当前状态如何从脉证中被辨识”，治疗次序等工作保留，但不再替代入口建设。 我此前的任务安排没有守住这个优先级。[置信度：高；依据是上一轮指定任务及126AT所述交付内容。]

该结论成立的充分必要条件：若目标是重建辨证论治体系，可追溯的状态判断是下游决策论证的必要基础；但它不是疗效成立的充分条件。至于“辨证正确”的充分条件，目前不能冒称已经建立，必须另用独立材料与结果检验。
