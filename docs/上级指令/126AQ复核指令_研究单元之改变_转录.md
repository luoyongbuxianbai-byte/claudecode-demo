我实际拉取了 126AQ d94af7d，检查了报告、M-01、抽取工具，并回读了太阳篇总结、§265、§282。你的批评有明确证据：问题已经不是某一条没查到，而是读过的整体理论没有约束后续判断。 我此前的复核也没有把这一点落实，责任不能只推给 Code。

先把这次真正错在哪里说清楚。

太阳篇总结〔讲伤寒·202144〕明确说：

“冷啊，衰沉啊，脉也微呀也细呀，这一系列的都发现，这叫做阴性病。”

紧接着〔202213〕：

“所以少阴病一讲，脉微细，但欲寐，人就消沉，就困顿，而且脉也比较微细。”

这就在 Code 已读范围内。它直接说明：脉参与病性阴阳的判断，而且与整体证候合看。

不过也要分清：单凭“三病位两病性”，不能证明每个脉象怎样对应阴阳；上面这段才是具体依据。正确研究问题应当是：

胡老怎样把脉的表现与精神、寒热、汗、津液等合起来，判断阴阳？何时能判，何时不能判，哪些反证会改变判断？

Code 却把它收窄成“有没有一句符合正则表达式的脉→阴阳直判句”。研究对象被检索工具的能力替换了。

这次还有几项同根错误：

Code 的判断	实际证据允许说什么
疑似时取脉，因此脉不是起点、只有疑似时才用	原文说明一个使用场景，没有规定唯一出场顺序
某段没用脉，因此这里脉不管用、不需要脉	没写到使用，不等于无诊断价值
浮不能单独定麻黄汤，因此“脉定纲不定方”	只能证明这些场景中，单凭浮或浮数不足以定方
三毒共同入口是脉证不相应	所引宿食材料讲的是程度与津液变化，不能强合成同一种推理
十四病理单元没有“脉”，所以模型缺项	脉是观察通道，病理单元是待解释状态；缺的是连接证据，不是必须增加一个“脉单元”
血管液体充分与末梢血流难抵达方向相反	液体含量、血流、部位不是同一个量；尚不能据此判矛盾

尤其最后两项，Code 在批评你的层级问题时，自己又混了层级。

⸻

你要我们研究的内容，我现在这样完整表述，而不把它冒充已经证明的结论：

辨证研究的对象，是患者在特定时间和条件下的机体状态。脉、舌、腹、汗、二便、饮食、精神及其他反应，是认识这个状态的不同途径。八纲、六经、三毒承担哪些分类、解释和决策功能，需要通过原文中的实际判断与治疗行为重建。研究必须说明：哪些观察支持哪些状态，哪些只是间接表现，哪些由别处受累而来；什么能排除什么，什么不能；状态如何限制治则、治法、药物、配伍、剂量和治疗次序；治疗后什么变化支持原判断，什么变化要求改判。最后检验这些对应是否稳定、能否复现、是否存在竞争解释。

“最终回归八纲六经三毒”的工作含义，是每次分析都必须交代这些工具究竟怎样参与判断，不能空着三栏，另用我们自造的模型完成全部推理。 但若材料暴露出它们尚不能充分表达的变量，也必须保留，并检验是否需要补充，而不是强塞进去。

你强调的“什么决定什么、什么导致什么”，还必须分别研究：

* 识别关系：某表现为什么支持一种状态。
* 因果关系：这个表现为什么发生。
* 决策关系：知道这个状态后，为什么采取或禁止某种处理。

三者能够相互支持，却不能互相替代。能据脉作判断，不等于已经证明脉产生的生理机制；药后好转，也不自动证明原来的机制解释正确。

⸻

我用刚刚回读的 §282 示范：怎样从“摘录”进入“理解作者怎么做”。

这段有欲吐不吐、心烦、但欲寐，随后自利而渴。胡老没有把“渴”直接归热，也没有把篇名“少阴”覆盖整个人。

1. 保留观察关系。
    他把“欲吐不得吐而心烦”连起来解释；同时保留“但欲寐”。这里已经涉及停饮与少阴表现的并存，不能只留几个孤立症状词。
2. 加入状态来历。
    作者解释为原本虚，再因下利损失津液而渴。这里的渴不是孤立观察，而与原状态及后续变化有关。这是作者的因果解释，须与观察记录分开。
3. 提出竞争判断。
    当前口渴究竟提示里热，还是虚损？不能凭“渴”本身裁决。
4. 寻找能够分辨的其他观察。
    〔284760〕作者明确说：“或者以脉，或者以尿。”本条具体展开小便的辨别作用。这说明观察通道可以协同、补充，并没有规定脉只能最后出场。 作者对尿色的具体断言，仍须另查适用范围与反例，不能直接当现代诊断定律。
5. 回接病位、病性与病程。
    他讨论少阴传里、太阴虚寒、津液不足，又与里热竞争解释比较。于是病位、阴阳寒热、虚、停饮、病程不是几张并列表，而是在同一次论证中发生联系。
6. 交代决策后果与证据缺口。
    不同判断会改变治疗方向；但本段没有一份完整的实际治疗结果，不能补写“因此已经验证”。同样，本条提到脉可协助，却未在此完整列出具体分辨脉象，下一步应回接已有相关段落，不能虚填。
7. 提炼作者的读法，并检验它。
    〔285197〕他说：“这个书必须得整个看。”这里的“整个看”有具体操作：把本条与太阴自利不渴、太阳篇小便清的鉴别连起来，检查同一个“渴”在不同背景下怎样改变意义。不是把更多引文摆在一起。

这才是在研究同一状态如何经不同观察被识别，以及不同状态为何产生相似表现。 也才真正接近你要求的对应关系。

6. 本批验收看两件事：你能否从材料重建作者实际判断；换到另一段时能否正确运用并主动发现边界。阅读数量、新增字段、撤回次数均不替代这两项。医学运行规则继续冻结。

为什么反复犯错？ 从这次可观察到的过程看，是“先抽句子→按预设栏目归类→写一句总规律→用后来的例子补限制”。这个流程容易把条件丢掉，把局部使用变成全局规定。我此前不断修最后的总规律，却没有要求先重建并检验整次判断，因而没有解决根因。更深的内部原因我不能仅凭报告断定。

结论：现在需要改变研究单元——从“某句话说了什么”，转成“一次完整判断是怎样成立、怎样可能失败的”。 原文、读法、脉证、状态、八纲六经三毒、治疗与反馈，都必须在这个单元内发生实际联系。[置信度：高；依据是本次直接回读及对现行推论的核对。]
