## 一、⑤【状态组合优先于六经归属】——否定面成立，肯定面须改为三分

**锚**〔A级·§236·C卷/讲伤寒/传真三源同文〕

> 「阳明病，**发热汗出者，此为热越，不能发黄也**；但头汗出、身无汗、剂颈而还，**小便不利**，渴引水浆者，**此为瘀热在里，身必发黄**，茵陈蒿汤主之。」

→ 同为阳明，汗出者不发黄，小便不利者发黄。**发黄之成因是「热＋湿」组合，非阳明本身。**

### 实测：C卷 224 条【辨证要点】之陈述方式

| 陈述式 | 条数 | 占比 |
|---|---|---|
| 纯状态 | 132 | 58.9% |
| ⭐**纯方证名** | 22 | 9.8% |
| 状态＋方证名 | 34 | 15.2% |
| 经名＋状态 | 9 | 4.0% |
| ⭐**纯经名** | **0** | **0.0%** |
| 三者皆无（词表缺口） | 27 | 12.1% |

⭐ **本表最硬之数：纯经名 0 条。无一条辨证要点靠经名判。**
此数**不随状态词表之完备性变化**（补词表只在「状态」与「未采」之间移动），故为**稳健结论**。
→ **上级⑤之否定面（「不靠经名判」）完全成立。**

### ⛔ 订正：上级⑤只列二分，实测出第三式

上级列「状态／经名」二分。实测第三式：**以方证名陈述**，56 条＝**25.0%**
例：「**桂枝汤证又见白虎汤证者**」「**桂枝去芍药汤证而痰涎多者**」

→ **正确表述：辨证要点之陈述单位有三——状态／方证名／经名(0)。**
「方证名」既非状态亦非经名，是「以已知方证为单位」，此即胡老「方证是尖端」之陈述形态。

### ⛔ 三数同报（不以补词表之涨幅充成绩）
含状态陈述者：**补词表前 67.9% → 补后 78.1% → 人读上界约 88%**
（余 27 条逐条读皆为状态，系词表未覆盖，非第四类）

### ⛔ 统计不证明规范性
本表只证明「要点以状态写」，**不证明「组合优先于归属」之应然主张**——
后者须由 §236 那类**同经异证**原文锚支撑，不由统计支撑〔R24 共现≠归属〕。

### ⑩ 之裁定：接受
**六经＝检索框架／状态组合＝实质结构。**
**0% 纯经名即其实测形态：经名在要点里从不单独承担判断，只作索引。**

## 三、⑨【功能位模型】症状-功能位-填充药表（C卷 89 条）

⭐ **上级⑨核心断言「功能位由症状定义，非由药性定义」——本表结构即其证明**：
**89 条句式之主语全部是症状（Y），药（X）在从属位置。** ✅ 成立。

### ⛔ 执行线自查（R41⑪ 同型·第 12 例）

## 五、⛔ 剂量判据层建表失败——系我方 61 批估计错误·自纠

**61 批原话**：「**已探底，可建**。实测『用量…故』24 处｜『重用X』60 处……**规模约 24–60 条**。」

**本批实测**：

| 阶段 | 条数 |
|---|---|
| 原始命中 | 383 |
| ⛔ 正向闸门弃（「重用/增/加重」后须紧跟已知药名） | **362** |
| 　└ 「增」后非药名（增加/增强/增大） | 278 |
| 　└ 「重用」后非药名 | 38 |
| 　└ 「加重」后非药名 | 36 |
| 过闸门 | 21 |
| ⭐ **跨书去重后**（同一方解在C卷/解读/传真三版重出） | **10** |
| ⭐ **言明「故治…者」者＝真判据** | **5** |

⛔ **裁定：剂量判据层建不起来。61 批之「已探底，可建」是错的。**
那个 24–60 是**未过闸门的原始命中**，与 precedent_scan「有力」62 次实得约 12 处同型
——**第 5 次「机械探底数被正向闸门砍一个量级」。**

⛔ **并撤销本批自己的一个动作**：执行线曾按上级 61 批要求对这 5 条做
「增强本位／兼填第二位」机械分类（得 4:1）。**撤销**——
**N＝5 时机械分类无意义**，且其中「增桂枝→关节痛、肢体肿**而气冲呕逆**者」归为「增强本位」本身可疑。
**分类须人读，本批不出分类结论。**

✅ **但这 5 条本身是真判据，照录**：

| 操作 | 故治（＝所填之位） |
|---|---|
| 倍用麻黄 | 汗出有热喘而急迫 |
| 增厚朴 | 小承气汤证而胀满较剧 |
| 重用橘皮 | 橘皮汤证哕逆剧烈而急迫 |
| 增桂枝 | 风湿关节痛、肢体肿而气冲呕逆者 |
| ⭐ **重用生姜** | **小半夏汤证而有头眩心悸的茯苓证** |

⭐ 末条是**「兼填第二位」之明证**：加量所填者为茯苓所主之水饮位。

→ **剂量层之正确定位：不是一个「层」，是 5 条散在判据。并入附录L 三，不单独建层。**
