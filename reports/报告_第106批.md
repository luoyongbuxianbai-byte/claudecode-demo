## 三、⭐⭐⭐ 而您说「最重要的一层你跟 code 从来没做」——本批演算撞上了它

**一百零六批，所有演算都是两段直连：**

```
症候 ─────────────────────────────────→ 药物
```

**而胡老的实际结构是三段：**

```
症候 →〔① 八纲定性　② 六经定位　③ 三毒标记〕→ 药物
```

### 活证据（T4 实测，不是我读书推出来的，是演算跑出来的）

〔A·讲金匮·**58718**〕
> 「**津液虚的渴，加栝蒌根就对；要真是阳明有热的渴，那非加石膏不可，加栝蒌根也不对。**」

T4 病案有「口干思饮」。**演算器只认得「渴」这个症候，认不出这是哪一种渴**，
于是**同时**要求了石膏与瓜蒌 ⇒ 213 方中**零张**能全覆盖 ⇒ 报「须合方」。

**⛔ 但真相不是须合方。真相是我们跳过了病性那一层。**
**「渴」定不了药。「阳明有热之渴」定石膏，「津液虚之渴」定瓜蒌，而且两者互斥。**

⇒ ⭐⭐⭐ **这就是您说的那一层的确切所指：不是某一族判据被漏掉，
是【八纲／六经／三毒】作为中间层，从来没有被算过。表里有这三栏，演算器根本不读它。**

⇒ **这也是 R84「症状无定性」在药味层的同型——而这一次不是读出来的，是被演算撞出来的。**

⛔ **已立为闸门 16 的核心禁令**：遇多义症候（渴／厥／烦／满／痛…），**须先判八纲之性再取药；
未分性而径取药，必然同时要求互斥之药。且在八纲层接上之前，「须合方」的结论一律不可信。**
