**背景**：上级容器网络关闭，不能 clone、不能读 git；用户是唯一传输通道。
实测：**上传的真文件（.md/.txt）从磁盘读，一次没失败过；粘贴的长文本失败十几次。**

## 约定
- **执行线 → 上级**：每批报告写成 `reports/报告_第N批.md`，commit 入库，并直接发送文件。
- **上级 → 执行线**：指令以文件形式回传，置于 `指令/指令_第N批.md`。
- **双方不再用长文本粘贴。** 用户只做搬运，不做复制。
